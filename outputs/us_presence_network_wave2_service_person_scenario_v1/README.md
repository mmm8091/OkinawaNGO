## 1. 这包回答什么

本包把五组人物消歧候选按 `very_high → high → moderate` 逐层放入情景，同时把已经核定的资金／资源边单独放在另一层，观察五个焦点组织 AWWA、KOSC、OESC、NOSCO、MTS 的连通结构如何变化。

它没有替负责人判断任何候选是不是同一人。图中的人物线全部是“**如果负责人接受该同一人判断**”才成立的条件投影；资金／资源线保留方向和现有审核边界。两层只在组织对层面比较是否重叠，从未合并成一种边，也不做全网中心性排名。

## 2. 先把结果说成人话

### 情景一：只接受 `very_high`

如果只把 Trinicia Kloepper 的同税期 AWWA／KOSC 双组织记录当作同一人，AWWA 与 KOSC 会先连起来。Lesilee Du Fresne／DuFresne 只会整理 OESC 自己的连续任职，不形成组织间人物边。

资金层已有三笔经负责人确认的 OESC→AWWA 申报记录。因此联合看两层时，AWWA、KOSC、OESC 已处在一个三组织分量，但连接方式不同：KOSC 通过条件人物边接到 AWWA，OESC 通过已核资金边接到 AWWA。两种关系尚未落在同一个组织对上。

五个焦点组织此时有 3 个联合分量：`{AWWA, KOSC, OESC}`、`{NOSCO}`、`{MTS}`。

### 情景二：再加入 `high`

Brooke Epp／Epps 若被接受，会成为 AWWA–KOSC 的第二项人物候选；它增加了同一组织对上的人物证据，但没有把新的组织带进来。

Amber N Tracy／Amber Tracy 若被接受，会把 AWWA 与 OESC 也用人物任职链连接起来。由于 OESC→AWWA 已有三个税期的资金记录，这时 **AWWA–OESC 成为唯一同时出现人物候选和已核资源流的组织对**。

这项唯一的多层重叠完全依赖 `HR-USN2-01c` 的人物同一性人审；01c 若不接受，重叠数立即回到 0。

重要的是，联合分量仍然是 3 个，AWWA 所在分量仍是 3 个组织。high 候选带来的不是更大的覆盖，而是 AWWA–OESC 这一既有关系的多层重叠：资源流入与相邻角色链可能发生在同一对组织之间。

### 情景三：再加入 `moderate`

Jen Yapsing／Jennifer Yapshing 若被接受，NOSCO 才会经人物候选接入 AWWA。此时 AWWA 所在分量由 3 个扩大到 4 个，五个焦点组织的联合分量由 3 个降到 2 个：`{AWWA, KOSC, OESC, NOSCO}` 与 `{MTS}`。

因此，“AWWA 把更多军属俱乐部串在一起”的**覆盖范围**主要依赖目前最弱的 moderate 候选；较强的 very_high／high 证据更支持的是 AWWA 周边已有关系的重复与叠层。

### MTS 为什么仍单列

MTS→Lions 的 USD 10,000 已按负责人决定保留为“止于 Lions 中介”的资源边，但 Lions 在五个焦点组织之外，所以它不改变五组织内部的分量数。W2-A 中两笔 MTS→AWWA 申报行仍是 `ai_seeded`，本包明确排除，未借它们把 MTS 接进 AWWA 分量。

这也说明 AWWA 不是唯一通道：即使当前人物候选以后全部成立，MTS 仍显示一条绕开 AWWA、先到 Lions 的外部中介路径。

## 3. AWWA 的位置可以形成什么更强的假设

当前可以提出、但仍须由负责人和更多原件检验的假设是：

> AWWA 可能不仅是接收并再分配资源的中介，也是军属俱乐部换届人物与行政经验汇聚的接口。服务侧组织不一定靠正式上下级关系组成网络，而可能通过“俱乐部人员轮换／兼任 + 对 AWWA 的重复资金输入”形成一种松散但可持续的中介结构。

这比单说“AWWA 收到钱”更强，因为它把两种不同机制放在同一组织对上检验：

- OESC→AWWA 有三个税期的已核资金输入；
- Amber 的 high 候选若获接受，会在同一 AWWA–OESC 组织对上补出相邻的人物角色链；
- AWWA–KOSC 在 very_high／high 情景下可能有两组人物候选，但目前没有同等级的已核资金边；
- AWWA–NOSCO 的接入只在 moderate 候选成立后出现；
- MTS 仍有经 Lions 的旁路，AWWA 不是排他性中心。

它仍然不能被写成“AWWA 控制其他俱乐部”“AWWA 是正式伞状上级”“人物兼任导致捐款”或“AWWA 对整个服务生态最有影响力”。当前只能说，在这五个组织和已纳入的证据里，AWWA 是唯一把多个组织接到一起的条件性交汇点；这个位置同时受选择框、IRS 披露和未完成人物消歧影响。

## 5. 数据边界与仍缺什么

1. 五项人物同一性均仍待负责人决定；本包没有创建 person node 或正式人物边。
2. 现有候选集中在 AWWA、KOSC、OESC、NOSCO；没有 MTS 与其他四组织的已消歧人物候选。
3. 五组织内部达到 `human_checked` 的资源关系目前只有 OESC→AWWA 三笔。MTS→AWWA 的两笔 IRS 记录未获负责人确认，因此只列在排除表。
4. MTS→Lions 只闭合到 Lions；没有向最终儿童医疗机构建边。
5. 税期、申报签署点和实际任期并不完全对齐；情景只比较组织连通性，不推断任职因果或交易因果。
6. AWWA 向地方 recipient 的支出不属于五家军属组织内部关系，未用于这里的连通分量。
7. 公开 IRS 资料对不同组织和年份的披露不对称。AWWA 的条件性桥接位置可能部分反映资料留存与当前选择框。
