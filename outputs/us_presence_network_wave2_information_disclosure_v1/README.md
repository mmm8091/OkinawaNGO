## 使用方式

1. 负责人先填请求人身份、地址、联系方式、费用上限和签名日期；
2. 全文搜索并清除所有方括号占位符和未采用的 OPTIONAL 段；WHS 稿以实际提交日更新截止日，并核对 modification 序列；
3. WHS 与 MCIPAC 草稿通过各自门户提交，不由本项目自动发送；MCIPAC 的门户路由字段与 FOIA 费用类别分别填写，并保存实际下拉选项截图；
4. 日本侧先电话确认保有部课和件数，再贴收入印纸、邮寄官方表格；
5. 保存提交文本、门户路由、时间戳、案号和所有修订；
6. 收到材料后另开事实接纳与人工复核，不直接改中央表。
