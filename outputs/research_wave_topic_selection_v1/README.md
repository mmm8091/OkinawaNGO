# Research wave topic selection v1

This directory governs the additive research wave authorized on 2026-07-20.

It does not modify or supersede the central registry, edge tables, source log, reviewed frontend layer, or the current exploration-system data contract.

Files:

- `topic_register_v1.csv`: competing and nested paper directions with go/hold conditions.
- `literature_map_v1.csv`: external scholarly interfaces; inclusion here does not add a source to the central source log or approve a project claim.
- `literature_search_log_v1.md`: bounded search record and novelty limits.
- `module_contract_v1.json`: module-index boundary and requirements for any future separately approved row-level export.
- `principal_checkpoint_v1.md`: the ready-now interpretation checkpoint after the three pilots.
- `frontend_research_modules_v1.json`: three-module directory and asset index; not a row-level frontend contract and not integrated.
- `wave_manifest_v1.json`: adapter asset hashes and boundary validation.
- `validation_report_v1.md`: concise no-write/no-contract-change check.

The three executable packages live in sibling directories:

- `outputs/research_wave_h1_documentation_visibility_v1/`
- `outputs/research_wave_h2_two_ecologies_v1/`
- `outputs/research_wave_h3_frontline_memory_v1/`

All are `research_only` and `not_frontend_ready` until a separate human decision, module-specific source/review gates, and a separately validated row-level export.
