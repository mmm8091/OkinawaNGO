# REG-01 Registry 扩展候选包 v1

日期：2026-07-12

## 结论

本轮建立 36 个候选。2026-07-12 已将其中 20 个 E4、无明显重名风险的主体按“身份级”安全合并进主 registry（A087-A106），registry 由 103 增至 123，达到原方案 120–180 的数量下限。分类、别名、议题/地点/事件/关系边仍待 HR-010；其余 E3、沿革和范围候选待 HR-011–HR-013。

这 25 个不是“补足 17 个”的机械凑数。其构成为：20 个冲绳本地 actor、5 个日本国内法律／女性／本土声援桥梁；其中包含 5 个先岛／宫古 actor、5 个劳工或教职组织、3 个女性组织、4 个噪音诉讼法律／协调 actor、3 个环境健康／水议题 actor。一次性 MMC 署名者没有进入首批。

## 建议第一批入表（25 个）

### P1：直接补原方案模块缺层（22 个）

- C001–C009：本地 NPO、教职／劳工、女性与社区层。主要改善 R1 分类生态，并为 R2/R5 提供过去缺失的组织类型。
- C012：`沖縄を再び戦場にさせない県民の会`，改善 R2、R3、R5、R9 的近年前线化与全县动员层。
- C013–C017：宫古反部署、和平运动、水／环境 actor，直接改善 R3 先岛组织清单与 R4 框架分析。
- C018：PFAS 市民联络会，补足基地污染—饮水—健康—行政听证的强解释链，改善 R2/R3/R4/R5。
- C019：うるま导弹部署市民会，为“先岛之外的自卫队部署与生命安全”增加可比案例，改善 R3/R4/R5。
- C020：冲绳／琉球弧之声会，补跨岛公共教育与场域桥梁，改善 R2/R3/R5/R6。
- C021–C024：全国公害律师网络、全国基地爆音原告团联络、嘉手纳与普天间律师团，改善 R4/R5/R8 的诉讼角色与重复共同行动证据。

### P2：具有持续一手行动记录的本土桥梁（3 个）

- C025 日本YWCA：有组织正式边野古声明和持续妇女人权网络。
- C035 首都圈“边野古海不填土”联络会：多年独立行动，不是一次性署名者。
- C036 大阪行动：至少自 2014 年持续固定行动，有自有记录与外部记录。

## 暂缓／合并复核（11 个）

- **范围连接不足**：C010、C029–C034。它们的法人／组织身份大多可以确认，但当前只能证明广义和平教育、环境或社区功能；在找到与基地、先岛、生活安全或研究事件的实质连接前不入表。
- **身份重复风险**：C026 第4次嘉手纳原告团、C027 普天间第2次原告团、C028 石垣“止める住民の会”。这些候选研究价值很高，但可能分别是 A052、A053、A010 的代际名称、前身或相关组织。应先建立 alias／lineage 判断，不可直接新增造成重复。
- **第二来源不足**：C011 女性团体联络协议会目前由女性财团事业记录间接确认；待取得组织自有页、章程或正式名单再决定。

## 为什么这些候选能改善解释，而不只是改善数量

1. **R1 组织生态**：现有 registry 没有劳工／教职组织，女性组织几乎只有 A049。首批把工会、教育、女性、地方 NPO 与法律协调网络纳入，能真正回答方案所列的组织类型，而不是继续堆叠国际环保署名者。
2. **R2 组织—议题网络**：新 actor 为和平教育、劳动、人权、PFAS、地下水、噪音法律和前线化提供独立组织基础，降低 bridge 图对边野古国际环保 actor 的依赖。
3. **R3 地点空间**：C013–C017 使宫古从 A012/A013 两个 seed 扩为反部署—和平网络—地下水—持续环保 NPO 的可比较生态；C019 增加うるま部署案例。与那国组织级缺口仍不能靠本轮线上候选虚构解决。
4. **R4 框架机制**：C015、C018、C019 分别提供地下水／生命、PFAS／健康、导弹／生命安全三条文本框架；C021、C023、C024补法律转译角色。
5. **R5 共同行动**：C022 是明确的跨基地原告团协调组织；C021 是律师横向网络；C035/C036 是持续本土行动。它们允许研究“重复公开协作”，但仍不得自动称稳定联盟。

## 入表前的人工门槛

每个 `add_first_batch` 候选需完成以下检查：

1. 与安全合并前的 103 actor 做规范名、别名、旧称、前身和诉讼代际去重；当前正式 registry 为 123。
2. 至少保存一个一手来源；E3 候选补第二来源后再进入正文主图。
3. 明确 `actor_class`、法律身份、主要地点和议题标签的证据依据；组织使命与单次行动分开编码。
4. 先岛 actor 记录首次／最近公开活动时间，避免把事件型委员会写成持续组织。
5. 劳工、服务、教育和女性组织只按公开功能和行动编码，不预设统一政治立场。
6. 噪音诉讼团体按“案件代际—原告团—弁护团—全国联络”分层；共同政府要请只算事件关系。

## 推荐的实际合并次序

1. 先合并 P1 中 E4 且无明显重名者：C001–C008、C013–C014、C016–C022、C024。
2. 补第二来源后合并：C009、C012、C015、C023。
3. 最后处理本土桥梁：C025、C035、C036，并在 registry 中标明 `japan_domestic` 和持续行动依据，不混入冲绳本地核心层。
4. C026–C028 先进入 alias／组织谱系核查，不占用新 actor ID。

## 来源边界

- 本轮优先采用内阁府 NPO Portal、县／市议会和政府记录、法院判决、组织官网、组织正式声明及律师／原告团自有资料。
- 地方新闻用于确认成立、代表或具体行动时降为 E3，并要求后续第二来源。
- 已安全合并主体的 source URL 已分配正式 source_id 并进入归档流程；未合并候选的 URL 仍是候选来源。
- `proposed_id` 仍是候选包排序占位；正式 actor_id 以 `merge_manifest_v1.csv` 为准，不能从 proposed_id 推定。
