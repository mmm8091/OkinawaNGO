# MT-006 ONC / JICA / 外务省 行政协作链 memo v0

日期：2026-07-03

**目标**：把 ONC（沖縄NGOセンター）的制度关系落到公开来源上，并**把行政协作与抗争型运动网络分开**。守口径：没有合同/项目/金额报告，不写"资金链"。

## ONC 是什么

- 特定非営利活動法人 沖縄NGOセンター（Okinawa NGO Center, ONC）。1999 年以市民推动的"沖縄NGO活動推進協議会"成立，2008 年取得 NPO 法人格并改名 ONC。宜野湾市。（S095）
- 定位：冲绳县内**国际协力 / 国际交流 / 多文化共生**的中核 NGO。做开发教育、冲绳移民史、多文化共生讲座、日本語サークル、志愿者协调、发展中国家研修受入等。
- **关键**：ONC 的业务是国际开发协作与多文化共生，**与边野古 / 基地抗争网络没有直接关系**。它属于行政协作 / 公共外交层，不是运动 actor。

## 澄清与纠错

- **F019（ONC ↔ 县知事公室基地对策课 A074）下调为 E2 / not_supported**：ONC 的行政关系在多文化共生 / 国际协作一侧（外务省相談員、县多文化共生、冲绳市、JICA），**不是**基地对策课。原 F019 疑为 AI 初筛把"ONC 与县政府协作"误配到基地对策部门，应视为未支持。
- 外务省 NGO 相談員是 MOFA 委託的顾问角色，可写"ONC 是外务省指定 NGO 相談員"，但**不得**写成"外务省资助冲绳 NGO 网络"——这是 ODA 市民参与的行政安排，金额/合同未见公开件。
