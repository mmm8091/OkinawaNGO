# Ambitious recipient-publication voice reconnaissance v1

日期：2026-08-22

状态：`lead_only`。本包沿既有线索 `UF-L2-001` 做三步以内的有限侦察；不进入 W2-F 结论、中央事实层、人工复核队列、publication adapter 或前端。

## 1. 侦察问题

在 Ambitious 自办刊物中，对 AWWA 的福利合作／正面叙事，与涉及基地、美军暴力、战争及美军统治的批判或距离话语，究竟由谁说出？它们是同一个人的稳定立场、不同栏目的并置，还是跨期出现的不同声音？

本包只做作者、组织角色、栏目和时间消歧，不把个人专栏写成机构立场，也不把 recipient 的合作写成对美军存在的政治接受。

## 2. `lead_only` 观察摘要

1. **2012 年第 127 号确实在同一期并置两种声音。** “10 月报告”以未署名的活动报道介绍 AWWA 资格视察和福利贡献；“ヒトツナギの志”则明确署名照喜名通，以美军暴力事件说明刻板印象：他把实施暴力的个别军人与更多军人区分开，同时又明确说这并不表示美军没有责任，并要求适当回应。前者属于刊物／机构活动报道，后者属于具名个人随笔，不能合并成一条机构政治立场。
2. **照喜名不是外围投稿者，但 2012 年的精确职务仍未闭合。** 第 100 号在 2010 年称其为事务局长；当前官网称其为团体发起人、副理事长及现场运营负责人。这足以把第 127 号专栏理解为资深内部人的个人声音，仍不足以把该专栏自动升级为董事会或机构声明。
3. **刊物编辑权并不等于照喜名个人。** 第 100 号编辑后记称，照喜名只负责到约第 20 号，2004 年起由另一位编辑接手。因此，2012、2023 年未署名的 AWWA 活动报道不能仅因刊物由 Ambitious 发行就归到照喜名个人名下。
4. **同一名高级内部人士后来直接参与 AWWA 合作。** 第 265 号记载，2024 年 AWWA 基地内晚宴上，照喜名本人致谢并说明 33 台便携电源的地方配置。这闭合的是“同一人参与福利合作”，不是“同一人撰写全部 AWWA 正面文案”。
5. **跨期个人专栏没有形成稳定反基地立场。** 2017 年照喜名把“基地”与战争、贫困等列为负面新闻，却说这些问题对自己不是高优先事项；2020 年他以战时反美、米军统治和战后亲美转向说明价值观变化并表达和平愿望。它们显示政治／军事问题反复进入个人随笔，但多被用作类比或被主动降到福利实践之后，而不是持续的组织倡议。
6. **较强的线索是“角色分区”，不是意识形态归类。** 当前材料允许提出一个未来问题：地方福利中介是否能一边接受、感谢并转用基地侧资源，一边在个人或其他栏目保留对军事暴力的有限问责与政治距离。它不能支持 Ambitious“亲基地”“反基地”或“因受赠而改变立场”的结论。

本轮没有在这些页面中发现可闭合到问责侧组织的共享人物或正式组织桥。由于只检查 Ambitious 的有限刊物链，这不是 Bridge audit 的负面结果。

## 3. 步数与停手

- 起点：`UF-L2-001` 的第 127 号同刊分区观察；
- 第 1 步：拆分署名个人、未署名活动报道与重复刊物叙事；
- 第 2 步：核照喜名组织角色、编辑权交接及跨期个人随笔；
- 第 3 步：核同一人 2024 年对 AWWA 的具名致谢，并收束“角色分区”线索；
- 共 9 条观察，未超过三步／十条边界。

继续判断机构编辑政策、董事会政治立场或受赠是否改变对美态度，需要会议记录、编辑责任记录或访谈，已超出本次线上侦察，因此停止。
