# R9 选举／公投与市民组织连接：程序阶段 brief v0

日期：2026-07-12

## 1. 本轮回答了什么

本轮把名护 1997、与那国 2015、冲绳县民投票 2019、石垣 2018–2024 从四个单点 `referendum_initiator` 事件，展开为“发起—签名/请求—议会/行政—投票/司法—结果”的程序链。

核心增量不是增加四个事件名称，而是说明同一种“住民投票”标签背后至少有三种不同路径：

1. **公民直接请求成功进入投票，但结果与行政决定分离**：名护收集 17,539 个有效签名，条例经市议会修正后投票，反对票过半；三天后市长仍宣布接受海上基地并辞职。名护市官方年表同时记录了反对多数与行政接受，显示咨询型投票不是法律否决权（R9S001–R9S003）。
2. **自治体条例主导的投票，用于确认既在推进的部署**：与那国通过个别条例并实施投票，632 票赞成、445 票反对；町长随后把结果解释为部署争议已经“决着”，但也承认约四成反对。这里不能把 A014 反对委员会写成整个投票的发起者或执行者（R9S005–R9S008）。
3. **公民直接请求形成条例与全县投票，并把结果转成外部通知资源**：2019 县民投票由 92,848 个有效签名启动，经县议会立法、三选项修法后在全 41 市町村实施；反对为 434,273 票（71.7%），知事再依据条例向日美政府通知。市民动员、议会立法、行政执行与国际/中央政府对象是连续但不同的角色（R9S009–R9S013）。
4. **签名门槛达成但投票被议会与司法程序阻断**：石垣 14,263 个有效签名超过有权者四分之一，市长两次提交条例案、议会两次否决；居民转向义务付け诉讼，2020 年那霸地裁以行政诉讼上的处分性等程序理由驳回。2021 年市议会又删除自治基本条例中的住民投票条款。该案把 R9 与 R7/R8 直接接起来：组织行动对象由选管/市长和市议会转到法院，制度通道本身也发生改变（R9S014–R9S018）。

## 2. 四案对照

| 案例 | 公民发起/签名 | 议会或行政转换 | 投票/司法 | 可解释的机制 |
|---|---|---|---|---|
| 名护 1997 | 推进协议会直接请求；17,539 有效签名 | 市议会把原案改成四选项并立法 | 实际投票；反对过半；市长之后接受并辞职 | 动员成功不等于结果约束行政 |
| 与那国 2015 | 当前无法证明由 A014 发起；主要是个别条例路径 | 町议会/町长制定并两次修法 | 实际投票；赞成多数 | 投票可以是自治体确认既有政策方向的装置 |
| 县民投票 2019 | A051 候选组织推动；92,848 有效签名 | 县议会立法；为全县实施加入第三选项 | 全县投票；结果由知事通知日美 | 市民请求经制度化后成为自治与外部倡议资源 |
| 石垣 2018–2024 | 14,263 有效签名，超过四分之一 | 市议会两次否决；2021 删除常设条款 | 未投票；转向多轮司法 | 制度否决会把公民行动从选举/议会场域推向法院 |

## 3. 对 actor-role 编码的修正

R9 不应只保留一个 `referendum_initiator` 字段。至少需要区分：

- civic initiator / signature organizer；
- formal request representative；
- signature verifier / election administrator；
- ordinance proposer / council decision body；
- campaign committee；
- voter or resident collective；
- judicial plaintiff / defendant / litigation supporter；
- post-result executive decision maker；
- result-notification target。

同一组织在多个阶段可有不同角色；市长、议会、选管、法院是程序 counterpart/venue，不应为了画网络一律升级为运动 actor。

## 4. 证据边界与人工复核点

1. **A068 名称问题**：官方资料使用“名護市民投票推進協議会”，现 registry 为“名護市民投票の会”。需要确认是否同一组织及正确 canonical/alias。
2. **A014 不闭环**：与那国条例、投票和结果可以在线确认，但“住民投票を成功させるための実行委員会”的正式名称、代表和持续性仍只有位置鲜明的杂志线索，必须当地/一手复核。
3. **A051 角色链**：官方资料确认直接请求和签名数，但现有主表没有可靠的一手组织页把 A051、元山仁士郎及请求代表完整连接起来。
4. **A011 官网失效**：`ishigaki-tohyo.com` 当前已变成无关旅游站；2026-07-11 的 S051 本地归档也是该无关内容，不能继续作为 E4 组织证据。需 Web Archive、原始页面/PDF或组织留存材料。
5. **石垣两条诉讼链可能混淆**：2020 义务付け诉讼判决有法院原文；后续投票地位确认诉讼到最高裁的案号、各审判决和 2024 终局决定尚未取得一手文件，暂为 `needs_human_review`。
6. 名护最终四选项票数应从市选管官方 XLS 人工读取；当前反对/赞成合计来自地方新闻回顾。
7. 与那国结果数字尚缺町选管原表；町长施政方针只是行政解释，不代表全体町民共识。

## 5. 对基础研究问题的解释增量

R9 现在能比“哪些团体参与公投”多回答一步：

> 冲绳民间组织把基地或自卫队部署争议转译为地方自治，不是一次性完成的。它依赖签名门槛、条例设计、议会处理、行政执行和司法可诉性。不同制度节点会修改、放行、阻断或重新解释公民动员；组织因而会在签名、议会、投票、法院和外部通知之间移动。

这一结论仍是过程机制比较，不是“公投导致政策改变”的因果识别。下一步可用 `process_stage_v0.csv` 与 `actor_role_candidates_v0.csv` 直接生成四案小倍时间线或 actor–stage–venue 图，并与前期知事选研究讨论“选举表达”与“议题单独表决”的差异。
