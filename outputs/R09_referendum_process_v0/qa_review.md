# R9 住民投票过程模块交叉复核

复核日期：2026-07-13
复核性质：非原作者交叉 QA；未修改主数据、控制文档或 R9 原始候选表。

## 1. 总体结论

R9 的四案比较框架可以保留，但当前版本**不宜整包直接合并**。28 条阶段记录、20 条 actor-role 候选和 21 条来源记录的内部外键均通过，四案的基本制度链也成立；不过，石垣案的第二次条例提案主体、两条诉讼链、来源映射和证据等级存在会改变解释机制的实质问题。

本轮建议：

- 可直接合并：名护官方票数、石垣两次议会决定的准确日期与第二案提案主体、2020 年地裁“却下”的程序性质、2021 年条例条款删除日期、A051 的组织—请求代表官方闭环。
- 人工复核后合并：A068 规范名、A011 的组织连续性和诉讼角色、石垣第二条诉讼链及最高裁程序标签、与那国官方选管结果。
- 拒绝：S051/S139 作为当前可复现 E4 证据；“市长两次提交条例案”；把两条石垣诉讼压成一条；把 A011 写成法院确认的组织原告；把 A014 写成住民投票发起或实施主体。

## 3. 高优先级事实修正

### 3.1 石垣第二次条例案不是市长再次提交

R9ST023 和 brief 当前写成“市长再次付议”。石垣市议会官方记录显示，2019-06-17 的第二案是**議員提出議案第2号**，即议员提出；第一次条例案则于 2019-02-01 被否决。机制应改为：

`直接请求 → 市长提交／议会首次否决 → 议员另行提案／议会再次否决`

这比“市长两次提交、议会两次阻断”更能解释制度入口的变化。

- 第一次议决：[石垣市议会 2019-02-01 议案结果](https://www.city.ishigaki.okinawa.jp/soshiki/gikai/teireikairinnjikai/teisyutugianntokekka/reiwagannnenndo/1310.html)
- 第二次议决：[石垣市议会 2019-06-17 议案结果](https://www.city.ishigaki.okinawa.jp/soshiki/gikai/teireikairinnjikai/teisyutugianntokekka/reiwagannnenndo/1314.html)

### 3.2 石垣存在两条诉讼链，不能继续合并

第一条是实施义务付け等诉讼：

- 那霸地裁：令和元年（行ウ）第14号・第15号，2020-08-27；全部诉被“却下”。这是程序性／适法性处理，不是对部署政策是非的实体判断。
- 福冈高裁那霸支部：令和2年（行コ）第3号。现有官方特别保存表可确认案号；裁判全文和精确结论仍应补齐。

第二条是地位确认性质的当事者诉讼：

- 那霸地裁：令和3年（行ウ）第5号，2023-05-23。
- 福冈高裁那霸支部：令和5年（行コ）第6号，2024-03-12。
- 最高裁：地方媒体和 CALL4 均指向 2024-09-26 的决定，此后败诉确定；但尚未取得官方决定书和最高裁案号。

OTV 使用“上告棄却”，QAB 使用“上告不受理”，二者的程序含义不同。在取得最高裁原件前，安全写法只能是“2024-09-26 最高裁决定后败诉确定”。

## 4. 各案证据与机制复核

### 4.1 名护 1997

名护市官方 XLS 核得：选举人 38,176，投票者 31,477，有效票 30,906，无效票 565，投票率 82.45%；赞成 2,562、条件付赞成 11,705、反对 16,254、条件付反对 385，合并赞成 14,267、合并反对 16,639。原表总数正确，但 R9ST005 可由地方新闻 E3 升为市官方 E4。

注意分母：16,639 占全体投票者约 52.85%，占有效票约 53.84%。报告最好直接写票数，若写百分比必须注明分母。官方 XLS 内某个当日投票小计存在 90 票差异，不影响上述总计，但不应引用该小计。

解释机制可保留：直接请求成功并举行投票，不等于形成有法律拘束力的项目否决；投票多数与投票后的市长决定发生分离。

- [名护市官方结果入口](https://www.city.nago.okinawa.jp/kurashi/2018071901216/)

### 4.2 与那国 2015

条例第23号及 2015-01-13、2015-01-16 两次修正目前来自大阪大学法规数据库，属于结构化法律二手材料 E3，不是町公报原件。条例文本支持“町长执行、选管受委任办理投开票”，但不能据此把 A014 写成发起者或实施者。

QAB 同期报道明确使用 `住民投票を成功させるための実行委員会`，并称 `上地国生委員長`。因此，A014 的事件期公开名称和负责人可达 E2；仍未闭合的是成立、法人状态、成员、持续性，以及它是否参与正式直接请求。

632 赞成、445 反对、17 无效、1,276 名选举人、85.74% 投票率仍主要来自地方报道。町长施政方针只确认赞成 58.7% 并承认约四成反对，不能替代选管原表。当地调取重点应是町选管结果表、町公报和议会记录。

- [QAB 2015-02-23 报道](https://www.qab.co.jp/news/2015022363334.html)

主解释框架应继续是安全前线化、地方自治、台湾邻近和生活／健康风险，而不是环境阻工。

### 4.3 冲绳县 2019

当前表把 A051 与元山仁士郎的角色停在 E3，理由是缺少组织—请求代表映射；这个缺口已可由官方材料闭合。冲绳县议会委员会记录明确列出：

- 元山仁士郎：`「辺野古」県民投票の会代表`、条例制定请求代表者。
- 安里長従：该会副代表、请求代表者。
- 中村昌樹：该会成员／关联身份、请求代表者。

县公报还列出 33 名请求代表者。因此 A051 的事件期组织身份、元山代表角色和组织参与发起／直接请求可升到 E4。

边界必须保持：33 名请求代表者不自动等于全体组织成员，92,848 名有效签名者更不等于成员；事件期角色也不能自动证明组织在事件后的持续性。

- [冲绳县议会委员会记录](https://www.pref.okinawa.jp/_res/projects/default_project/_page_/001/021/212/h301002gun-1.pdf)
- [冲绳县公报号外第17号](https://www.pref.okinawa.jp/kenkouhou/H30/5gatsu/180523gogai17.pdf)

### 4.4 石垣 2018–2024

除 3.1–3.3 所列修正外，A011 应严格区分“组织”“27 名请求代表”“匿名居民原告”和“诉讼支持者”。法院判决能证明请求、签名与当事人程序事实，却没有把这些个人全部认定为 A011 成员，也没有把 A011 本身列为原告。

CALL4 的组织自述可支持 2018 年 10 月成立、金城代表和诉讼支持角色，但它是平台上的组织侧材料，宜作 E3，不是法院 E4。A011 可暂列“公开可见的组织者／诉讼支持者”，不能写成“法院确认的组织原告”。

## 6. 来源与证据等级审查

### 6.1 S051 / S139 必须降格或拒绝

S051 虽在主 source log 标为 verified E4 且归档成功，但当前域名和本地 `raw.html` 均是无关旅游网站“石垣島ヘイヨー”。这次“成功归档”只证明抓到了错误内容，不能支持 A011、14,263 份签名、六年活动史或解散。R9S017 将其标为 E0／archive mismatch 是正确的。

同域旧 PDF S139 当前为 404／failed，也不能在缺少历史副本时继续作为可复现 E4。两者应进入历史网页恢复或当地材料任务，不得静默沿用旧等级。

### 6.2 R9S014 / R9S015 已在主 source log，映射缺失

- R9S014 的同一 URL 已是 S138，应补 `existing_source_id=S138`。
- R9S015 的旧 URL 已是 S137，应补 `existing_source_id=S137`，并把 URL 更新为法院迁移后的 `/assets/hanrei/hanrei-pdf-89731.pdf`。其状态不是 `online_only_not_in_main_archive`，而是旧 URL 导致的 archive failure。

### 6.3 地方新闻等级需统一

当前 coding schema 通常把地方新闻归 E2，而 R9S004、R9S007、R9S019、R9S020 多处写成 E3。除非项目明确增加“同期／多源核验后的地方新闻可升 E3”规则，否则应按 schema 统一。尤其 A014 的 QAB 证据应保守记 E2。

## 8. 修正后的解释机制

R9 最有解释力的共同机制不是“公民投票是否成功”，而是公民诉求如何在多个制度关口被转译：

`动员／签名 → 签名审查 → 条例议程设置 → 议会决定 → 行政执行 → 司法可诉性`

四案显示不同关口：

- 名护：直接请求、条例和投票均实现，但结果没有形成行政上的法律否决。
- 与那国：行政与条例路径促成投票，结果被町长解释为推进依据；反对组织不是实施主体。
- 冲绳县：公民组织通过正式请求代表进入议会制度化，投票结果再转化为知事对日美政府的通知资源。
- 石垣：第一次直接请求案被议会否决，第二次议员提案再被否决；司法策略从实施义务付け转向地位确认，条款删除又改变了后续机会结构。

这个比较可以说明“同为住民投票动员，为何产生不同制度结果”，同时避免把投票、组织动员、行政决定和法院判断压成单一的胜负叙事。
