# R2 actor-issue robustness v1

The leave-source-out result is not uniform. S003 and S006 have little effect under the independent-support rule, while removing S004 cuts the ecology-to-international bridge set from 8 to 4. Removing S003/S004/S006 together still leaves 4 such actors and retains 78.8% of all cross-frame actors. The international perimeter is therefore partly list-dependent, but a smaller core survives.

The largest overall contraction occurs in the human-reviewed-only layer (59 edges versus 236 full E3+ edges). This is currently an audit of review completeness as much as a substantive robustness test. Both qualifications matter: S004 materially shapes the outer bridge layer, while incomplete edge-level human review limits how much of the remaining core can be presented as final.
