# 信息公开小型试验：负责人发送前检查点 v1

状态：`not approved to send`

本页不是请求文本，也不应替代现有三份 `draft_not_sent` 草稿。它只把日后真正提交前必须由负责人作出的选择压缩成五项。

## 1. 美国请求人的真实费用身份

选择一项并留下证明：

- `all_other/non-commercial`：无法证明请求由教育／非商业科学机构授权时的稳妥选择；首两小时检索和首 100 页复制为法定免费额度，后续以费用估价协商。
- `educational institution`：须确实以教育机构角色、在其授权下为学术研究提出；不收检索费，复制费只从第 101 页起计算。
- `noncommercial scientific institution`：须确实由合格机构授权，研究不为推销特定产品或行业；同样不收检索费，复制费只从第 101 页起计算。
- `fee waiver`：不是类别替代项。只有能真实说明“显著增进公众对政府运作理解、且主要目的不是商业利益”并说明公开传播计划时才申请。无力支付费用不是理由。

建议：若没有现成的机构授权与传播材料，先选第一项、USD 50 cap、明确“估价超过上限前请联系以缩窄范围”。

## 2. 是否发出三条微请求

分别决定 `approve / revise / defer`：

1. `MVP-01`：WHS award-execution packet；
2. `MVP-02`：MCIPAC one-year installation financial-statement locator；
3. `MVP-03`：冲绳防卫局 FY2024 one-document pilot（先做咨询）。

若批准，实际提交仍由负责人或获授权的具名请求人完成；本项目不得代为发送。

## 3. 请求人信息与费用

- 美国两项：姓名、邮寄地址、email、电话、真实类别、费用上限、是否确有 fee-waiver 依据；
- 日本一项：姓名／法人名、代表者、日文地址、电话、联系人、收入印纸和邮寄费承担方式；
- 不可为节省费用而虚报机构或媒体身份。

## 4. 对转送与拒绝的立场

预先选择：`accept referral + accept partial release + request segregable portions + request fee estimate before expansion`。

如收到正式 `no_records`、`not_held`、部分不公开或全不公开决定，先按 `response_visibility_coding_v1.csv` 归档；是否上诉或另投由负责人另行决定。

## 5. 发送后，哪些事情仍不能做

- 不将请求或案号写成研究发现；
- 不将机关回复直接写回中央表；
- 不因一份 no-record／拒绝回复推出资金链、隐瞒动机、真实不存在或合法性效果；
- 不因此解除 W2-F、W2-G、publication 或前端门禁。
