# R10 官方行政协作来源总体层 v1

日期：2026-07-13
来源：S002《令和6年度「NPO等との協働実績調査」》本地归档 PDF，86 页、616 条编号记录

## 一句话结论

冲绳县公开协作表显示的不是单一“补助金网络”，而是一套以**委托、提案型委托、指定管理和补助／物的支援**为主、并包含共催、后援、委员会、事业协力和讲师等机制的公共协作生态；但表内 partner 名称、事业费和同表出现都不能自动转写为 registry actor、实际付款、稳定关系或政治立场。

## R10 基础问题：哪些主体进入公开行政协作与可见资源渠道？

1. **总体不是少量一期核心 actor。** 616 行包含 390 个不同 source-literal partner 字符串，经 NFKC 与 PDF 换行清理后得到 365 个 machine display aliases。二者都不是“组织数”；JV、复合体和缩略名尚未做人类身份合并。
2. **公开渠道高度制度化。** 官方 C1 委托 303 行、C2 提案型委托 60 行、C3 指定管理 13 行、C4 补助／助成／物的支援 93 行，合计 469/616（76.1%）。这只说明官方协作形态，不说明每行的 actor payment 或补助决定额。
3. **可见度集中于公共服务部门。** 前五个部门为 保健医療介護部 121行、教育庁 101行、生活福祉部 83行、こども未来部 71行、文化観光スポーツ部 67行，共 443/616（71.9%）。因此 R10 的总体层首先刻画福利、医疗、教育、儿童与文化旅游等公共服务生态，而非反基地组织的资金网。
4. **一期相邻议题只是总体的小部分。** 官方 field10“人权／和平”8 行、field11“国际协力／交流”11 行，共 19/616（3.1%）。其中可见新外交イニシアティブ、冲绳和平协力中心、冲绳 NGO 中心和多个国际交流／共同企业体 source cells；是否并入 actor 层仍由 HR018／HR032 分别控制关系与身份。
5. **高频名称只能称 source labels。** 当前频次较高的 machine display aliases 包括 社会福祉法人沖縄県社会福祉協議会（20行）、公益社団法人沖縄県看護協会（15行）、一般社団法人沖縄県医師会（10行）、公益財団法人沖縄県建設技術センター（10行）、公益社団法人沖縄県緑化推進委員会（9行）、特定非営利活動法人サポートセンターゆめさき（8行）。这些计数不能被称为网络中心性；法律形态缩写、同名变体与 JV 成员仍需人审。

## 解释边界

- C4 官方定义同时涵盖补助金、助成金和物的支援，不能把全部 C4 行写成现金 grant。
- S002 的“事业费”是项目口径；即使 partner 有名，也不能由该列推断向其支付同额。
- source label 同名重复不等于法人身份已合并，也不等于稳定行政伙伴或网络中心。
- JV／共同企业体按原 source cell 保留，不把项目费拆给成员。
- S002 公开出现不恢复 HR-013 已移出 registry 的 A094，也不把一般公益组织自动写成一期核心 actor。
