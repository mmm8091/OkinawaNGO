# Registry expansion 组织级门槛审查 brief v1

日期：2026-07-13

## 审查问题与门槛

本轮不是从九个名字里“挑两个补到 120”，而是逐一检验四个条件：

1. 正式身份能否回溯到组织／政府／正式法人记录，并完成名称与代表或组织形态的核对；
2. 是否有法人连续性、跨年正式记录或长期行动，而不是一次出现；
3. 是否有至少一条与一期议题直接相连的组织使命、持续项目或具名行动证据；一次署名不能满足；
4. origin layer、与既有 actor 的去重关系和解释边界能否写清。

机器 gate 采用三种结果：

- `ready_for_human_decision`：证据条件闭合，可由人工决定 add/defer/reject/历史限定；
- `not_ready_online`：仍缺关键在线证据；
- `out_of_scope_candidate`：身份可能闭合，但不能修复本轮模块缺层，或其状态使其不宜用于当前扩样。

## 候选解释

### C010：全称必须纠正，不能自动政治化

官网给出的正式名称是 `公益財団法人沖縄県女師・一高女ひめゆり平和祈念財団`，原候选名是官方简称。它的价值是长期和平教育、战争记忆和代际传承，不是反基地运动节点。建议把 `peace` 作为稳健 issue；`women` 是否是组织议题还是历史对象，应由 HR-013 决定。

### C011：不是 A094 的别名

冲绳县 2024 名单同时列出 C011 会长伊良波纯子和 A094 `一般社団法人沖縄県女性連合会` 会长与那霸信子，说明二者是并存组织。C011 的旧候选 URL 属于おきなわ女性財団，只能作为项目二源。女団協从 2016–2024 持续承办课程，2023 年安保三文书课程和 2004 年地位协定讲座提供直接一期连接。22 个加盟团体不能自动生成联盟边。

### C015：此前暂缓理由已被新二源实质改变

2015 宫古每日、2018 民医连材料和 2019 琉球新报都以岸本邦弘为代表，名称在 `配備を考える会`、`配備について考える会` 和带引号的 `基地配備` 形式间变化。跨年连续性和地下水—自卫队／导弹部署连接已经出现，机器侧可以重开；人工仍须决定这些变体是否属于一个组织、哪个名称作 canonical，以及 2019 以后未见材料是否影响入表。

### C029：有 actor 身份，不等于当前活跃

内阁府 NPO 记录显示法人和年度申报仍在，章程明确和平传播，2014 年还以主办者身份举办边野古专题研讨会。因此它不是一次署名名称。但 FY2021–FY2024 报告反复写“无主要活动”，若人工入表，必须标记 `dormant_or_no_principal_activity_2021_2024`，不能画成当前运动核心。

### C030：明确不用于凑数

该法人 2021 年报告写明休业，内阁府记录显示 2025-12-07 因 NPO 认证撤销而解散；在线只闭合了泛化的垃圾资源循环宗旨，没有闭合具日、实质的一期行动。它可以在将来的组织谱系／解散史模块中重新考虑，但不应修复当前 120 下限。

### C031–C034：是环境生态层，不强迫挂接军事争议

C031 的海岸清扫、C032 的珊瑚与植树、C033 的漫湖湿地修复和环境教育，都可以作为 R1/R2/R3 的一般环境对照层；没有证据时一律不附加反基地／反部署立场。C034 由冲绳县项目促成，成员横跨行政、NPO、企业和研究机构，origin 应优先审 `mixed_or_network`，不能把它改写为纯基层组织。其官网明载政治中立，也不能把成员关系写成稳定联盟。

## Origin layer 与本土声援边界

本轮九个候选中没有 `japan_domestic` 本土声援候选。C029 虽有东京从属办公室，主事务所、法人主管机关和组织根基均在冲绳；C034 则是冲绳场域中的跨部门混合网络。若以后审 MMC Tier B／本土声援组织，必须另设 `japan_domestic solidarity` 层，不能拿来改变冲绳本地 actor 构成。

## 人工决定后才允许的动作

只有 HR-013／HR-011-C015 明确决定后，主线程才能依次：

1. 为获准 actor 分配不冲突的 A 编号并写入 registry；
2. 将获准来源提案分配 S 编号、归档并做人审元数据；
3. 单独建立 actor–issue、actor–place 和 event observation，不能从本包字段直接机械生成；
4. 对 C011 会员、C015 联合行动、C034 成员网络继续执行“事件／成员不等于稳定联盟”；
5. 对 C032／C033／C034 的行政或项目记录继续执行“项目存在不等于资金关系”。

本包本身不批准上述任何写入或关系结论。
