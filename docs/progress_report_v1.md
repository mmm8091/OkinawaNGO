# 冲绳民间组织 / NGO 分类与议题网络 一期进度报告 v1

日期：2026-07-01

## 一、研究问题

冲绳民间组织 / NGO 如何把基地问题转译为环保、生活安全、地方自治、人权、法律程序和国际倡议等议题？这些组织在边野古、与那国、先岛等关键地点中扮演了什么样的公开角色？

本阶段不做复归以来全量 NGO 网络，先做可复核的分类底库与重点议题网络原型。

## 二、研究方案调整

在原有冲绳本土 NGO / 市民团体之外，本期已将以下方向纳入观察：

- 日本本土环保、和平、法律、人权 NGO 与冲绳议题的连接。
- 外来 NGO / 国际倡议网络（2010 年 67 团体共同声明、2015 年 31 团体紧急声明等跨国倡议链条）。
- 美军基地社区服务组织（USO、军属福利、配偶俱乐部慈善网络）。
- 公共外交 / 青年交流项目（TOMODACHI、美国领馆项目等）。
- 资助 / 委托 / 赞助关系（外务省 NGO 相談員、JICA、企业赞助等）。
- 政府机构作为制度节点（沖縄県基地対策課、沖縄防衛局等）。

所有新增方向仅作为"观察层"，不预设政治立场，不将服务型组织自动编码为反基地或亲基地。

### 议题网络概况

核心议题链条（出现频率最高）：

1. **anti_base（反基地）** — 最多组织涉及的议题
2. **international_advocacy（国际倡议）** — 跨国声明和法律渠道
3. **biodiversity / environment（生物多样性 / 环保）** — 大浦湾、儒艮、珊瑚
4. **peace（和平）** — 和平运动与反战框架
5. **legal（法律）** — 爆音诉讼、环保诉讼、行政法
6. **referendum / local_autonomy（住民投票 / 地方自治）** — 石垣、宫古、2019 县民投票
7. **life_safety（生活安全）** — 噪音、地下水、健康风险
8. **frontline_prevention / Taiwan_contingency（前线化防止 / 台湾有事）** — 近期安全环境议题

### 地点覆盖

- **边野古 / 大浦湾（Henoko / Oura Bay）** — 最多组织关联的地点，跨环保、法律、国际倡议多条链路
- **冲绳全县** — 广域市民网络和协调组织
- **石垣** — 住民投票运动、地下水和生活安全
- **宫古** — 反导弹部署和水资源问题
- **与那国** — 前线化、住民投票、健康风险（证据较薄，需当地补查）
- **嘉手纳 / 普天间** — 爆音诉讼和基地负担
- **高江** — 直升机场反对和山原森林保护

## 四、证据分级说明

对资助、委托、赞助和项目合作关系，本项目采用五级证据分级：

| 等级 | 名称 | 可用措辞 |
|---|---|---|
| E4 | 证据确凿 | "证据显示""公开记录确认" |
| E3 | 基本确认 | "公开资料显示""基本确认" |
| E2 | 可信线索 | "存在相关线索""仍需核查" |
| E1 | 未确认说法 | 不进入结论 |
| E0 | 排除 | 不进入结论 |

只有官方记录、组织财报、项目报告、grant / award / contract 等能够支持的关系，才会进入结论；新闻、活动页、社媒或二手资料仅作为待核查线索。
