# 需要用户/甲方判断的问题

## 1. 一期是否要明确避开“完整历史网络”

建议：避开。

推荐表述：

> 标准一期不承诺 1972 年以来全量 NGO 网络，而是建立可扩展的组织分类底库和重点议题网络原型。

需要甲方确认：是否接受把完整历史网络放到长期扩展。

## 2. 与那国专题的主轴

建议：不要把与那国强行写成“环保拒止”。

更稳主轴：

- 台湾距离
- 沿岸监视队
- 住民投票
- 电磁波/健康风险
- 前线化
- 地方自治

需要甲方确认：是否接受“与那国 = 前线化/自治/健康风险案例”，而不是“与那国 = 环保案例”。

## 3. 是否要把“台岛以东治权问题”写入对外方案

建议：不要直接写。

对外方案更安全的表述：

> 先岛地区安全化、台湾周边安全环境、地方自治与民间组织反应。

需要甲方确认：内部可以讨论更敏感的问题，但交付文档是否采用更中性的学术/政策语言。

## 4. 是否有图书馆/报刊数据库访问条件

如果没有：

- R6 媒体可见度只能做公开网页样本。
- 1972-1990s 组织谱系只能做线索，不可承诺完整。

需要甲方确认：是否能安排冲绳县立图书馆、报刊数据库或当地协作者。

## 5. 交付规模

建议标准一期：150-200 个 actor。

需要甲方确认：

- 轻量版：60-80 actor，偏 feasibility。
- 标准一期：150-200 actor，分类底库+网络原型。
- 扩展版：300+ actor，需要数据库/档案/访谈条件。

## 6. 是否允许使用党派媒体/活动者资料作为线索

建议：允许作为 seed source，但必须标注 source_type 和 confidence。

例如赤旗、活动者博客、组织 SNS 可以用于发现组织名和事件，但关键结论应尽量用地方新闻、官方资料、组织声明或多源交叉确认。
