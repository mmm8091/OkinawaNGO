# 一期交付逻辑简化建议 v0

日期：2026-06-08

对象：`复归后冲绳民间组织 _ NGO 分类与议题网络一期研究方案.docx`

## 1. 总体判断

用户提出的三层交付逻辑是正确的，而且比当前方案更适合对甲方沟通。

当前方案已经把数据底座、研究解释成果和上线展示成果分开，但仍然容易让甲方觉得这是一个“数据库 + 网页平台”项目。实际更稳的商业和学术交付逻辑应改成：

1. 主交付：研究报告 + 甲方论文。
2. 次交付：内部/私有可视化网页，用于展示和汇报，不公开数据。
3. 扩展交付：可持续扩展数据库和网页，作为后续多篇论文和长期项目的基础。

这样更符合甲方当前需求，也更容易报价。

## 2. 为什么要这样改

### 2.1 甲方最直接需要的是成果，不是平台

甲方真正能立刻使用的是：

- 一份能读、能讲、能修改成论文的研究报告。
- 一篇可继续打磨的论文草稿。
- 一套能支撑论文和报告的图表、数据表和方法说明。

数据库本身有长期价值，但如果第一阶段就把数据库和网页说成最大成果，甲方可能会觉得“花钱买了一个还没用起来的平台”。所以第一阶段应把数据库定位为支撑报告和论文的研究底座。

### 2.2 网页有展示价值，但不应压过研究交付

可视化网页是加分项，适合：

- 给甲方展示成果；
- 在汇报时让网络图、地点图、组织分类更直观；
- 后续内部维护和继续扩展。

但网页不应成为第一阶段的核心承诺。尤其是数据不公开时，网页更像是“私有展示端”或“内部演示站”，不是正式公共数据库平台。

### 2.3 真正高价值数据库应作为扩展交付

如果后续继续投入，数据库可以变成项目最值钱的资产：

- 持续补充 actor；
- 补媒体可见度；
- 补人物互锁；
- 补长期谱系；
- 补访谈和档案；
- 支撑多篇论文和政策报告。

但这应该作为二期或长期项目卖点，不要塞进一期主交付。

## 3. 建议改成三层交付

## 第一层：主交付，研究报告 + 论文

这是第一阶段的核心。

建议命名：

> 研究报告与论文支持包

交付内容：

1. 25-35 页研究报告。
2. 甲方论文草稿或论文框架深化稿，建议单独加钱。
3. 15-20 页汇报 PPT。
4. 5 个核心图表。
5. 3 个专题备忘录。
6. 方法说明、编码规则、资料来源说明。
7. 后续论文选题清单。

论文方向建议：

> 冲绳民间组织如何将反基地议题转译为环保、生活安全、地方自治和国际倡议网络？

这一篇最适合第一阶段直接做成主论文。

论文加钱的合理性：

报告和论文不是同一个东西。报告可以偏资料、图表和发现；论文需要研究问题、文献对话、理论框架、方法、论证结构和学术语言。因此论文应作为加价项。

## 第二层：次交付，私有可视化网页

这是展示型成果，不是主成果。

建议命名：

> 私有可视化展示页

交付内容：

1. 项目介绍页。
2. 方法说明页。
3. 组织分类图。
4. 组织—议题网络图。
5. 地点—议题图。
6. 与那国 / 先岛专题图。
7. 关键案例页。

建议删除或弱化：

- 数据下载页。
- 公开数据库入口。
- “持续更新的公共研究入口”。

建议改为：

> 网页仅作为甲方内部展示和汇报使用，数据不公开下载。后续如需公开版或持续维护版，可另行报价。

维护费：

维护费可以少一点，因为甲方未必长期使用。

建议：

- 静态网页交付后 1 个月免费修小问题。
- 之后维护费 1,000-3,000 RMB / 月。
- 若只是偶尔更新，可按次收费：1,500-5,000 RMB / 次，视更新量而定。

## 第三层：扩展交付，长期数据库与系列论文

这是长期项目价值，不是一期必须做完。

建议命名：

> 可持续扩展数据库与系列研究计划

扩展内容：

1. 从 120-180 actor 扩展到 300+ actor。
2. 增加媒体可见度模块。
3. 增加人物—组织互锁模块。
4. 增加复归以来组织谱系模块。
5. 增加访谈和档案资料。
6. 增加公开或半公开网页。
7. 形成 2-4 篇后续论文。

这层的价值表述：

> 一期报告和论文只是第一轮分析成果；真正可持续的价值在于沉淀一个冲绳 NGO / 民间组织议题网络数据库。若后续继续投入，该数据库可以围绕边野古国际倡议、先岛安全化、媒体可见度、人物互锁和长期组织谱系不断扩展，持续产出论文和政策分析。

## 4. 建议报价结构

### A. 研究报告基础包

核心内容：

- 研究报告。
- 数据底座。
- 核心图表。
- PPT。

建议价格：

> 7 周 / 148,000 RMB。

### B. 论文支持加价包

核心内容：

- 在报告基础上，单独写成甲方论文。
- 包括论文结构、研究问题、文献对话、方法、发现、讨论、结论。
- 可做 1-2 轮修改。

建议加价：

> +30,000-60,000 RMB。

如果只是论文框架和部分章节：

> +20,000-30,000 RMB。

如果要接近可提交课程论文 / seminar paper：

> +40,000-60,000 RMB。

### C. 私有可视化网页加价包

核心内容：

- 静态或轻量交互网页。
- 数据不公开下载。
- 展示核心图表和专题页。

建议加价：

> +25,000-50,000 RMB。

维护费：

> 1,000-3,000 RMB / 月，或 1,500-5,000 RMB / 次更新。

### D. 长期数据库扩展包

核心内容：

- 扩充 actor 数量。
- 补 R6 / R12 / R13。
- 增加媒体、人物、谱系和访谈 / 档案。
- 继续产出系列论文。

建议作为二期：

> 10-14 周 / 220,000-320,000 RMB 起。

## 5. 建议替换当前第6节标题

当前标题：

> 6. 一期交付成果

建议改成：

> 6. 一期交付成果：报告、论文支持与展示网页

当前三层：

1. 研究数据底座
2. 研究解释成果
3. 上线展示成果

建议改成：

1. 主交付：研究报告与论文支持
2. 支撑材料：数据底座、图表与方法说明
3. 次交付：私有可视化网页
4. 扩展交付：长期数据库与系列论文计划

## 6. 建议写给甲方的短版表述

> 本项目第一阶段的核心交付不是单纯做一个数据库，而是产出一份可使用的研究报告，并在此基础上支持甲方完成一篇论文。数据库、编码规则和图表是报告与论文的研究底座。网页展示可以作为加价项，用于内部汇报和可视化呈现，但数据不公开。若第一阶段显示资料密度和研究价值足够，后续可继续投入，扩展为冲绳 NGO / 民间组织议题网络数据库，并围绕边野古国际倡议、先岛安全化、媒体可见度、人物互锁和长期组织谱系持续产出多篇论文。

## 7. 我的判断

用户提出的简化方向是对的。建议下一版方案不要把“数据库和网页”放在最前面，而应把“报告 + 论文”放在最前面。

最适合的商业叙事是：

1. 先交付能立刻使用的研究报告。
2. 加钱帮助甲方形成论文。
3. 再加钱做私有可视化网页。
4. 如果甲方认可价值，再把数据库升级为长期项目，持续产出论文。
