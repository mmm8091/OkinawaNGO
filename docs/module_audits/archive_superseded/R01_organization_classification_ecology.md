# R1 冲绳民间组织分类与组织生态

## 核查结论

可做，价值高，一期核心模块。它直接回应甲方问题：“NGO 起了什么作用？”但分类必须采用多标签制，不能把每个组织强行归入单一类别。

## 已探查资料

- NPO 法人ポータル和冲绳县 NPO 资料可支持正式法人层。
- 2010、2015、2020 年边野古/儒艮/大浦湾相关共同声明可支持运动组织层。
- 石垣、宫古、与那国新闻材料可支持先岛地区市民团体层。
- OEJP、ノーモア沖縄戦、沖縄対話プロジェクト等组织网站可支持近期网络型组织层。

## 建议分类

一级分类建议：

1. 反基地 / 反军事设施
2. 环保 / 生态保护
3. 生活安全 / 健康风险 / 灾害避难
4. 地方自治 / 住民投票
5. 法律 / 诉讼 / 原告团 / 弁护团
6. 人权 / 和平 / 反战
7. 劳工 / 女性 / 教育 / 社区
8. 国际倡议 / 跨国 NGO
9. 行政协作 / 公共服务型 NPO
10. 媒体 / 研究 / 支援网络

## 可交付物

- 组织分类表
- 组织生态说明
- 组织类型 × 议题标签交叉表
- 重点组织小档案

## 难点

一个组织可能同时是反基地、环保、人权、国际倡议组织。比如 OEJP 同时连接环境正义、儒艮保护、美国机构和反边野古议题。因此必须允许多重标签。

## 判断

标准一期可以做出 150-200 个组织/团体/网络的分类底库。该模块价值和可行性都高，建议优先级维持最高。
