# R9 选举 / 县民投票与市民组织连接

## 核查结论

能做，但要谨慎。可以研究组织如何参与县民投票、住民投票和公开声明；不宜在一期承诺“组织动员导致选票变化”的因果分析。

## 已探查资料

- 2019 边野古县民投票公开结果和相关运动。
- 石垣自卫队配备住民投票运动。
- 与那国 2015 自卫队配备住民投票。
- 我们前一阶段已有 2014/2018/2022 市町村层面反边野古候选人得票数据，可作为背景连接。

## 可抽取字段

- election_or_referendum_id
- actor
- action_type
- public_position
- place
- issue
- result
- source_id

## 可交付物

- 组织参与投票/公投事件表
- 住民投票运动小档案
- 组织公开立场与投票结果背景图

## 难点

投票结果与组织动员之间存在因果识别问题。组织活跃的地方可能本来就更反基地，不能简单说组织导致投票结果。

## 判断

一期可做“组织—投票事件连接”，不要做因果模型。该模块可作为前一知事选项目与大项目的桥梁。
