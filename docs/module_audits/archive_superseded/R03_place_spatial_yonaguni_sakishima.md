# R3 地点与空间分布：与那国 / 先岛专题

## 核查结论

可做，价值高，但需要修正表述。与那国可以做，但它不是最强的“环保拒止”案例；更强的是“台湾距离 + 自卫队沿岸监视队 + 住民投票 + 电磁波/健康 + 前线化 + 地方自治”。

## 已探查资料

- 与那国町官方资料显示：与那国岛距冲绳本岛约 509km，距台湾约 111km。
- 陆上自卫队官方页面确认与那国驻屯地和与那国沿岸监视队等存在。
- 防卫白书将与那国置于南西诸岛安全保障语境中。
- 2015 年与那国住民投票新闻可确认自卫队配备争议和反对派关注点。
- 石垣、宫古公开新闻显示，环保/地下水/生活安全框架更强。

## 地点分工建议

- 边野古 / 大浦湾：环保、儒艮、珊瑚、国际倡议。
- 普天间 / 宜野湾：城市安全、事故风险、返还问题。
- 嘉手纳周边：噪音、生活安全、基地集中。
- 石垣：自卫队配备、住民投票、地下水、生态、标的化。
- 宫古：导弹/弹药库、地下水源、生活安全。
- 与那国：台湾距离、沿岸监视队、住民投票、电磁波/健康、前线化。

## 难点

离岛组织规模小、资料少，且很多争议通过地方报纸和少数活动者发声。与那国的组织网络资料比边野古少，不能承诺复杂网络图。

## 判断

一期可做“地点—议题框架”和“与那国专题小档案”，不宜承诺与那国完整 NGO 网络。
