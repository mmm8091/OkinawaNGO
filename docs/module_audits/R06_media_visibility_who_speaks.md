# R6 媒体可见度与“谁在发声”

## 结论

能做示范样本，但不适合一期承诺完整媒体可见度。若没有报刊数据库权限，只靠公开网页会有明显偏差。

## 已探查资料

1. 冲绳县立图书馆说明：馆内可用《沖縄タイムス》1997 年以后文章数据库和《琉球新報》1998 年 1 月以后冲绳相关文章数据库。
   - https://www.city.naha.okinawa.jp/lib/riyouannai/on-linedatabase.html
   - https://db.g-search.or.jp/g_news/QOKN.html
   - https://t21help.nikkei.co.jp/ryukyu/help/cat225/cat281/post-29.html

2. 公开网页可找到琉球新报、QAB、RBC、OKITIVE、赤旗、全国新闻关于石垣、宫古、与那国、边野古的部分报道。

3. 公开网页对近期和高争议事件友好，对旧组织、低可见度组织、地方小活动覆盖弱。

## 可抽取字段

- article_date
- media_name
- actor_mentioned
- speaker_name
- speaker_role
- issue
- place
- quote
- tone / frame

## 推荐抽样方式

一期不要做全量媒体数据库。建议按重点事件抽样：

1. 2015 与那国住民投票。
2. 2018-2023 石垣住民投票 / 自卫队配备争议。
3. 2015 以后宫古地下水 / 导弹基地争议。
4. 2010 / 2015 / 2020 边野古环保共同声明和国际倡议。
5. 2025 高市台湾有事答辩后的冲绳市民团体抗议。

## 可交付物

- 重点事件新闻样本表
- 主要发声主体列表
- 媒体可见度示范图
- “媒体偏差说明”

## 难点

公开网页不是全量数据库。Google 可见性会偏向：

- 近期资料
- 高争议资料
- 已数字化媒体
- 大组织
- 全国媒体引用过的事件

这会让一些离岛小团体、早期团体、馆内数据库里的报道被遗漏。

另外，“谁在发声”不等于“谁在组织”。媒体会偏向共同代表、知名活动者、知事、议员、律师、学者，后台组织者可能不可见。因此 R6 的结果只能说明媒体可见度，不能直接说明真实组织权力。

## 判断

一期可以做“重点案例媒体可见度样本”，不应承诺完整媒体可见度。若甲方需要该模块变成核心成果，必须追加图书馆/数据库访问。
