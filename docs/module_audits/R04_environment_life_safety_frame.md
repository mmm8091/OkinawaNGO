# R4 环保 / 生活安全框架与军事设施争议

## 结论

可做，价值很高，一期核心模块。甲方提到“当地人似乎想用环保来拒止自卫队和美军”，这个模块正好回答。但应写成“环保 / 生活安全 / 健康风险 / 地方自治框架”，不要只写环保。

## 已探查资料

1. 边野古 / 大浦湾：儒艮、珊瑚、大浦湾生态、环境影响评价、美国 Marine Mammal Commission，是“环保 + 反基地 + 国际倡议”的最强案例。
   - https://www.wwf.or.jp/activities/statement/3436.html
   - https://okinawaejp.blogspot.com/2020/07/
   - https://earthjustice.org/case/okinawa-dugong-proposed-airbase

2. 石垣：公开新闻中出现地下水、生态、工事中止要求、导弹基地争议、标的化等框架。
   - https://ryukyushimpo.jp/news/entry-1176922.html

3. 宫古：公开新闻中出现地下水源、导弹基地、弹药库、生活安全框架。
   - https://ryukyushimpo.jp/news/entry-296563.html

4. 与那国：电磁波、健康风险、前线化、说明不足、住民投票和岛内分裂更强；环保框架相对弱。
   - https://ryukyushimpo.jp/news/prentry-239307.html

## 可抽取字段

- action_type
- evidence_quote

## 推荐框架分类

- ecology：儒艮、珊瑚、海草藻场、地下水、生态系
- life_safety：噪音、坠机风险、弹药库、避难、事故
- health_risk：电磁波、污染、饮用水、PFAS 等
- autonomy：住民投票、县民投票、说明不足、地方合意
- frontline_risk：台湾有事、先岛前线化、标的化
- legal_environmental_procedure：环境影响评价、诉讼、行政请求

## 难点

不能把所有地方反对都归结为环保。石垣/宫古确有地下水和生态材料；与那国更偏电磁波、健康、住民投票、前线化。边野古是环保—国际倡议最强案例。

另一个难点是“环保”本身可能既是真实地方关切，也是反军事设施行动的合法化语言。写作时不要把它简单说成工具化，也不要浪漫化为纯生态运动；应承认它同时具有生活安全、地方自治和政治动员功能。

## 判断

标准一期应把 R4 列为核心模块。它最能对接甲方关于“环保拒止”的问题。
