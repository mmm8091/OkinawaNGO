# R10 法律 / 政策 / 环境程序渠道

## 结论

可做，价值高，但需要控制范围。边野古、儒艮、环境影响评价、石垣住民投票、与那国/宫古相关诉讼或行政程序都能形成样本。

## 已探查资料

1. Earthjustice dugong litigation：可作为美国法律程序样本，显示冲绳儒艮和边野古基地争议进入美国法院路径。
   - https://earthjustice.org/case/okinawa-dugong-proposed-airbase

2. OEJP / MMC civil society report：可作为美国联邦机构行政程序样本。
   - https://okinawaejp.blogspot.com/2020/07/

3. 边野古环境影响评价、儒艮保护、珊瑚和大浦湾生态相关 NGO 声明：可作为日本国内环境程序和政策请求样本。

4. 石垣住民投票诉讼 / 条例争议新闻资料：可作为地方自治与司法路径样本。
   - https://www.otv.co.jp/okitive/news/post/00007817/index.html
   - https://newsdig.tbs.co.jp/articles/-/1052600

5. 与那国住民投票后反对派曾表达诉讼或工事差止意向，可作为线索，但需要更强来源确认。

## 难点

法院文件和正式诉讼材料不一定全部公开。很多情况下只能通过新闻、组织声明、律师团材料间接确认。

另外，法律程序不能只看胜负。即使诉讼失败，它也可能产生议题公开、资料生产、国际关注、组织连接等社会运动效果。这个模块应记录“程序作用”，不只记录法律结果。

## 判断

一期可做小样本，不宜承诺完整法律资料库。边野古/儒艮最适合作为主案例。
