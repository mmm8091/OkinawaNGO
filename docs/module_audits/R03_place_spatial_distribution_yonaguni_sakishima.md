# R3 地点与空间分布：与那国 / 先岛专题

## 结论

可做，价值高，但需要修正表述。与那国可以做，而且与甲方后续关心的台海 / 先岛问题高度相关；但它不是最强的“环保拒止”案例。与那国更稳定的公开框架是台湾距离、自卫队沿岸监视队、住民投票、健康 / 电磁波、前线化、地方自治和岛内分裂。

边野古 / 大浦湾、石垣、宫古更适合承载环保和生活安全框架。与那国应放入“先岛前线化与地方社会反应”专题。

## 已主动探查的资料

1. 与那国町官方资料显示：与那国岛距离冲绳本岛约 509km，距离台湾约 111km。
   - https://www.town.yonaguni.okinawa.jp/docs/2023102400019/file_contents/tyoukieinou.pdf

2. 陆上自卫队官方页面确认与那国驻屯地和与那国沿岸监视队等存在。
   - https://www.mod.go.jp/gsdf/station/wa/yonaguni/

3. 防卫白书将与那国置于南西诸岛安全保障语境中。
   - https://www.mod.go.jp/j/press/wp/wp2022/html/nc014000.html

4. 2015 年与那国住民投票新闻可确认自卫队配备争议、投票结果和反对派关注点。
   - https://www.qab.co.jp/news/2015022363334.html
   - https://ryukyushimpo.jp/news/prentry-239307.html

5. 石垣、宫古公开新闻显示，环保 / 地下水 / 生活安全框架更强。

## 地点分工建议

- 边野古 / 大浦湾：环保、儒艮、珊瑚、环境影响评价、国际倡议。
- 普天间 / 宜野湾：城市安全、事故风险、返还问题。
- 嘉手纳周边：噪音、生活安全、基地集中。
- 石垣：自卫队配备、住民投票、地下水、生态、标的化。
- 宫古：导弹 / 弹药库、地下水源、生活安全。
- 与那国：台湾距离、沿岸监视队、住民投票、电磁波 / 健康、前线化。

## 难点

离岛组织规模小、资料少，且很多争议通过地方报纸和少数活动者发声。与那国的组织网络资料比边野古少，不能承诺复杂网络图。

另一个风险是叙事过度。不能把与那国简单写成“环保反基地”，也不能只写成“亲中 / 反美”。更稳妥的是写成：岛民围绕自卫队配备、前线化风险、地方自治、生活安全和健康风险形成争议。

## 判断

一期可做“地点—议题框架”和“与那国专题小档案”，不宜承诺与那国完整 NGO 网络。与那国专题能显著提高项目战略价值，但必须与石垣、宫古一起比较，避免单点材料过薄。
