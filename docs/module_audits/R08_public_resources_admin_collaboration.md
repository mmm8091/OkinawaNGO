# R8 公开资源 / 行政协作渠道

## 结论

能做，但不是甲方当前最关心的主线。它更适合解释冲绳 NGO 生态中的“公共服务型 NPO”和“行政协作型 NPO”，不一定能解释反基地/反军事设施组织。

## 已探查资料

1. 冲绳县 NPO 等との協働実績調査：可看到行政部门与 NPO 等组织的协作项目、事业名、协作对象和金额。
   - https://www.pref.okinawa.lg.jp/_res/projects/default_project/_page_/001/004/917/2r6hp.pdf

2. 冲绳县 NPO 页面和 NPO プラザ：可作为制度入口和法人信息入口。
   - https://www.pref.okinawa.jp/kurashikankyo/katsudo/1004889/1004890.html

3. 县、市町村委托项目、补助、公募资料可进一步追踪，但一期不建议作为主轴。

## 可抽取字段

- government_department
- project_name
- partner_organization
- year
- budget
- collaboration_type
- issue_area
- actor_id

## 可比较的问题

- 行政协作型 NPO 与反基地 / 抗争型组织是否是两套不同生态？
- 哪些组织可以同时进入行政协作和社会运动场域？
- 行政资源是否更偏向福利、教育、社区、儿童、环境保护等低冲突议题？
- 基地、和平、先岛安全化相关团体是否较少出现在行政协作表中？

## 可交付物

- 行政协作项目表
- 行政协作型 NPO 清单
- 抗争型组织与协作型组织对比表
- 资源渠道说明

## 难点

行政协作资料和反基地运动资料重合度可能不高。反基地、环保、住民投票、国际倡议组织往往不是行政协作项目承接主体。

这个模块还有解释风险：不能因为某组织没有行政协作项目，就说它“不重要”；也不能因为某组织有行政协作项目，就说它参与反基地运动。

## 判断

一期可以作为背景模块，不能作为主轴。若做得太大，会偏离甲方关心的“NGO 如何参与反基地/先岛安全化”的问题。
