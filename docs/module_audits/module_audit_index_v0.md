## 核心判断

第5节的菜单整体不是空想，绝大多数模块都能做出“可验证、可交付”的版本。但一期必须坚持样本型、分层型和证据型目标：先做 actor registry、issue taxonomy、place registry、source log 和若干重点议题网络，再扩展到长期谱系和完整媒体 / 人物网络。
