# R1 冲绳民间组织分类与组织生态

## 结论

可做，价值高，是一期核心模块。它直接回应甲方的关键问题：“NGO / 民间组织到底起了什么作用？”但分类必须采用多标签制，不能把每个组织强行归入单一类别。

## 已主动探查的资料

1. NPO 法人ポータル和冲绳县 NPO 资料可以支持正式法人层。
2. 2010、2015、2020 年边野古 / 儒艮 / 大浦湾相关共同声明可以支持运动组织层。
3. 石垣、宫古、与那国新闻材料可以支持先岛地区市民团体层。
4. OEJP、ノーモア沖縄戦、沖縄対話プロジェクト等组织网站可以支持近期网络型组织层。
5. Earthjustice、APJJF、WWF Japan、NACSJ、Peace Boat 等资料可以支持国际倡议和日本国内 NGO 桥接层。

## 推荐分类

一级标签建议如下：

1. 反基地 / 反军事设施
2. 环保 / 生态保护
3. 生活安全 / 健康风险 / 灾害避难 / 噪音
4. 地方自治 / 住民投票 / 县民投票
5. 法律 / 诉讼 / 原告团 / 弁护团
6. 人权 / 和平 / 反战
7. 劳工 / 女性 / 教育 / 社区
8. 国际倡议 / 跨国 NGO
9. 行政协作 / 公共服务型 NPO
10. 媒体 / 研究 / 支援网络
11. 桥接型组织：连接三个以上议题或两个以上行动场域

## 难点

一个组织可能同时是反基地、环保、人权和国际倡议组织。比如 OEJP 同时连接环境正义、儒艮保护、美国机构和反边野古议题。ヘリ基地反対協議会同时连接现场抗议、环境、生活安全、地方自治和反基地。必须允许多重标签。

另一个难点是“公共服务型 NPO”和“抗争型市民组织”资料来源不同。若只看 NPO 法人资料，会漏掉运动主体；若只看共同声明，会漏掉行政协作和日常服务组织。

## 判断

标准一期可以做出 150-200 个组织 / 团体 / 网络的分类底库。该模块价值和可行性都高，优先级应保持最高。
