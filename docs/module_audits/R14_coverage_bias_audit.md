# R14 资料覆盖与偏差审计

## 结论

这个模块必须做，而且可做。它不是装饰性方法说明，而是整个 NGO 网络项目的可信度保险。因为本项目天然会混用 NPO 法人资料、地方报纸、组织官网、声明、诉讼材料、行政资料、英文国际倡议材料和历史档案，如果不做覆盖与偏差审计，后续网络图很容易被误读成“全量事实图”。

一期建议把 R14 作为所有模块的共同底层规则：每个 actor、edge、event、issue coding 都必须有 source_id、confidence、review_status 和 coverage_note。

## 已主动探查到的资料结构

1. 官方 NPO / 行政协作资料：内阁府 NPO 法人ポータル、冲绳县 NPO 页面、冲绳县 NPO Plaza、认定 NPO 页面。这类资料适合识别法人型、行政协作型、公益活动型组织，但会漏掉大量非 NPO 法人的市民团体。

2. 组织官网 / 声明资料：例如 ヘリ基地反対協議会、OEJP、Peace Boat、NACSJ、WWF Japan 等。这类资料适合抽取议题、行动、共同声明和自我定位，但容易偏向仍在活跃、懂得网页传播、可见度高的组织。

3. 地方媒体资料：琉球新报、冲绳时报、QAB、RBC、OKITIVE 等。适合识别事件和人物，但公开网页覆盖不完整，旧文可能缺失或需要数据库权限。

4. 国际倡议 / 英文资料：Earthjustice、APJJF、国际 NGO、美国机构相关材料。适合识别跨国路径，但它们通常会放大环境、人权、法律框架，未必反映冲绳本地所有组织生态。

5. 历史档案资料：冲绳县公文书馆、县立图书馆、地方报刊数据库。适合追踪复归后长期演变，但需要更多时间、权限或实地访问。

## 需要审计的偏差

1. 法人偏差：NPO 法人资料会漏掉任意团体、市民連絡会、实委会、原告团、律师团、地主会、临时共同斗争组织。

2. 时间偏差：1997/1998 年后数字资料更多，1972-1990s 前半段更依赖档案、旧报纸和二手研究。

3. 媒体偏差：公开网页偏向近期、高冲突、高知名度、高争议组织；低调协作型组织和后台组织者容易消失。

4. 地点偏差：那霸、边野古、宜野湾、嘉手纳资料较多；石垣、宫古、与那国等离岛资料较分散，小团体更容易被漏掉。

5. 语言偏差：日文资料覆盖本地政治和行政；英文资料偏向国际倡议；中文资料常偏向地缘政治叙事，不能作为组织事实的主证据。

6. 类型偏差：行政协作 NPO 和抗争型市民团体来自不同资料系统，若只用一个入口，会把另一个组织生态排除掉。

7. 网络偏差：共同声明、诉讼、国际请求信会放大已有跨组织协作能力的团体；没有署名能力或不参与公开联名的地方组织会被低估。

8. 生存者偏差：仍有网站、仍被报道的组织更容易进入数据；已经解散、更名、转入线下活动的组织会被低估。

## 推荐审计字段

- source_id
- source_type
- source_language
- source_date
- source_scope
- source_access: open_web / database / archive / paid / fieldwork_needed
- actor_coverage_strength
- edge_coverage_strength
- known_missing_cases
- bias_type
- confidence
- review_status

## 可交付物

- `coverage_audit.md`
- `source_type_distribution.csv`
- `actor_confidence_distribution.csv`
- `missing_cases_log.csv`
- `source_access_log.csv`
- “不能据此推论的事项”说明，例如：不能从当前样本推论冲绳所有 NGO 的数量，不能把共同署名等同于稳定联盟，不能把 NPO 法人生态等同于抗争型市民社会生态。

## 判断

一期必须配套做。R14 的意义是主动告诉甲方和未来读者：我们知道数据不是全量，也知道每种资料会偏向什么，因此我们用分层来源、置信度和缺漏记录来控制解释边界。
