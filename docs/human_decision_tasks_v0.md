# 人类决策任务书 v0

日期：2026-06-17

## 1. 目的

本文件用于集中记录需要人类判断的问题。凡是 AI 无法仅凭公开资料稳妥决定、或会影响对外沟通口径、研究边界、政治解释风险和当地补查优先级的问题，都放到这里。

原则：

- 这里不是资料清单，而是“需要人类拍板 / 指派 / 确认”的问题清单。
- 每个问题都要给出背景、为什么需要人类判断、可选处理、建议动作和交付物。
- 聊天里临时抛出的问题，后续也应沉淀到本文件。

## 2. 使用方式

状态字段：

- open：待判断。
- assigned：已指定负责人。
- answered：已有明确判断。
- deferred：暂缓。
- closed：已处理并反映到数据或文档中。

优先级：

- P1：影响本周推进或第一次沟通稿。
- P2：影响一期数据质量或任务分配。
- P3：后续扩展问题。

### HD-004 第一次沟通稿是否写入外来 NGO / 军属服务方向

优先级：P1

状态：closed

背景：

新版方案已加入外来 NGO、军属服务组织、公共外交和资助 / 委托机构。但第一次沟通稿如果写太多，可能显得偏离原本“冲绳本土 NGO / 反基地 / 环保 / 先岛”的主轴。

建议判断：

- 第一次沟通稿主轴仍写“本土组织 + 重点议题网络”。
- 外来 NGO / 军属服务方向写成“新增观察层”和“下一步核查方向”。
- 不写成已经完成资金链分析。

用户决策：

- 第一次沟通稿只写研究方案已调整。
- 可以说明已将相关组织纳入观察对象，并建立了数据表。
- 用户会塞截图。
- 不展开敏感资金链分析。

沟通稿口径：

- 可写“新增外来 NGO、军属服务组织、公共外交 / 资助关系作为观察层”。
- 可写“已建立初步 actor 表和关系表”。
- 不把 USO / AWWA / NED / USAID 展开成分析结论，除非配截图需要。

### HD-006 资金关系措辞

优先级：P1

状态：closed

背景：

资金关系证据难度高。用户已明确可以写“基本确认有资助关系”这类分级措辞，但不能幻觉。

建议判断：

- E4：证据显示。
- E3：公开资料基本确认。
- E2：存在相关线索，仍需核查。
- E1/E0：不进沟通稿。

用户决策：

- 沟通稿不用写太细，除非出现重大发现。
- 只需说明资金关系证据会做分级，并大致说明依据类型。
- 不在第一次沟通稿里展开具体资金关系判断。

沟通稿口径：

- “我们会对资助、委托、赞助和项目合作关系做证据分级。”
- “只有官方记录、财报、项目报告等支撑的关系才进入结论；其他仅作为待核查线索。”

- 需要你判断是否对外写。
