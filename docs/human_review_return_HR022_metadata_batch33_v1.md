## 0. 批次边界

- 本批只复核来源题名、类型、年份／期间、URL、归档状态、locator、证据级别和支持范围。
- 来源层接受不批准 actor、组织连续性、actor-issue／actor-place edge、关系、联盟、因果解释或政策效果。
- 官方年表支持其中逐项记载的程序事实，但不能把并列发生的事件自动解释成因果链。
- 图上训练和国民保护计划支持公开设定、计划与程序，不验证现实撤离能力、安全性或居民同意。
- 施政方针支持町长的行政解释，不等于全体町民共识，也不授权后续所有扩军项目。
- 地方新闻按中央 schema 原则上为 E2；事件期具名不等于独立组织身份和持续性闭合。
- 议会记录必须区分议员提问／转述和行政答复；记录的官方性不把发言者的全部陈述变成政府认定。
- 本报告不修改 HR CSV、中央 source log、archive manifest、actor registry、候选边、图或正文，留待主线程统一合并。
