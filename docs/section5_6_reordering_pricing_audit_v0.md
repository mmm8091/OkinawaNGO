# 第5、6节排序、工期与报价调整建议 v0

日期：2026-06-08

## 1. 是否需要调整

需要调整，但不是推翻原方案。

原方案第5节的模块菜单整体方向成立；第6节三档报价也基本可用。但经过逐模块小样本核查后，发现模块优先级和工期边界需要重排：

1. R14 资料覆盖与偏差审计不应作为普通选作模块，而应作为必做质控机制。
2. R11 跨国 / 国际倡议网络应上调，因为它最能说明 NGO 如何把地方基地争议国际化。
3. R10 法律 / 政策 / 环境程序渠道应上调，但只能做样本，不做完整法律库。
4. R6 媒体可见度、R12 人物互锁、R13 长期谱系应下调到扩展版或长期版。
5. 标准一期 6 周 / 128,000 RMB 能做压缩版，但如果要把 R11、R10、R14 做扎实，建议改为 6-7 周 / 138,000-158,000 RMB。

## 4. 推荐对外报价

如果甲方只是想先启动：

> 推荐 A：4 周 / 58,000 RMB。

如果甲方希望正式做成一期成果：

> 推荐 B：7 周 / 148,000 RMB。

如果甲方希望后续可以接近论文 / 长期项目一期：

> 推荐 C：10-12 周 / 220,000-280,000 RMB。

如果甲方明确要求媒体数据库、人物网络和复归以来长期谱系：

> 推荐 C+：12-14 周 / 260,000-320,000 RMB。

## 5. 标准一期推荐交付

标准一期建议明确写成：

- 150-200 个 actor。
- 更稳口径可写为：120-180 个公开资料可核查 actor，150-200 作为资料允许时的上限目标。
- actor registry 与 actor alias。
- issue taxonomy、place registry、event/action taxonomy。
- source log、evidence notes、coverage audit。
- 组织分类表。
- 组织—议题网络图。
- 地点—议题图。
- 联盟 / 共同行动样本网络。
- 跨国 / 国际倡议样本网络。
- 法律 / 环境程序样本表。
- 与那国 / 先岛专题小档案。
- 边野古国际倡议专题小档案。
- 石垣 / 宫古生活安全专题小档案。
- 25-35 页初步研究报告。
- 15-20 页汇报 PPT。
- CSV / Excel 数据包。

明确不含：

- 1972 年以来全量 NGO 网络。
- 完整媒体可见度。
- 完整人物互锁网络。
- 完整组织谱系。
- 组织动员对选举 / 投票结果的因果估计。

## 6. 建议写入方案的短句

> 经小样本资料核查，本项目第一阶段应优先建设组织分类底库、组织—议题网络、地点—议题网络、环保 / 生活安全框架、共同行动网络、跨国倡议样本与资料覆盖审计。媒体可见度、人物互锁和复归以来长期谱系价值较高，但需要数据库、档案或访谈支持，建议列为扩展模块。标准一期建议调整为 6-7 周，报价区间 138,000-158,000 RMB；若按压缩版执行，可保留 6 周 / 128,000 RMB，但相应减少跨国倡议和法律程序深度。
