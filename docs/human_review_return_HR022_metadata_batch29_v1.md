## 0. 批次边界

- 本批只复核来源标题、类型、年份／期间、证据级别、locator 和可支持范围。
- 来源层的 `accept`／`accept_with_revision` 不批准 actor、actor-issue／actor-place edge、组织角色、联盟、因果解释或政策效果。
- 议会表决记录只支持相应议案和程序结果；不能推出组织连续性、联盟或后续授权。
- 国民保护计划、训练问答中的计划、假定和估算，不等于冲突将发生，也不等于现实运输能力、设施可用性或撤离可行性已得到验证。
- 市级交付金检证表可以支持其中明示的项目、实施方法、资金流标签和金额；来源进入 source log 本身不批准关系边，更不能把公共设施运营委托写成运动资金。
- 本轮只做线上调查，不启动当地资料、地方报纸数据库或馆藏任务。
- 本报告不修改 HR CSV、中央 source log、archive manifest、actor registry、候选边、图或正文，留待主线程统一合并。

### S170 的队列限制语与实际页面相反

队列称原摘录“空港や港湾などのインフラ”未在页面或附件找到。重新核查当前网页和本地归档 HTML 后，页面正文确实明确写道：

> 武力攻撃予測事態下的训练，作为“空港や港湾などのインフラが維持されているもの”进行讨论。

所以“训练情境假定机场和港口基础设施维持可用”这一窄释义是有直接来源支持的。

但它只能编码为：

- 沖縄县在本次问答中说明的**训练假定**；
- 运输请求以安全得到确保为前提。

它不能被改写为：

- 现实冲突中机场和港口会保持可用；
- 运输安全已经得到保障；
- 六天全岛撤离现实可行；
- 训练证明了基础设施韧性或撤离能力。
