# 公开线上资料能否支撑 150-200 个 actor 的复核说明 v0

日期：2026-06-08

## 1. 结论先说

不能把“150-200 个组织 / 团体 / 网络 / 机构条目”说得太死。

更准确的判断是：

> 纯线上公开资料足以支撑 120-180 个可核查 actor；如果纳入日本国内支援 NGO、国际 NGO、法律团体、行政 / 目标机构和一次性共同声明网络，150-200 个条目可以达到，但属于上限目标，不应作为硬性保证。

如果甲方理解为“150-200 个冲绳本地 NGO / NPO 法人”，那不稳，也不应承诺。

## 2. 为什么 150-200 不是完全没根据

公开资料中已经存在几个可形成 actor seed 的来源池：

1. 2010 年 WWF Japan 共同声明：国内 67 个团体，另有 550 多个全球团体署名。实际应只抽取其中与冲绳 / 边野古 / 环境倡议有关的核心节点，不应全量纳入 550 多个全球署名。

2. 2015 年 NACSJ 边野古紧急声明：31 个 NGO，其中包含日本国内、冲绳相关和海外环保 NGO。

3. 2020 年 OEJP / Marine Mammal Commission 请求：71 个冲绳、日本及海外团体。

4. 石垣、宫古、与那国地方新闻：可补充先岛地区住民团体、反自卫队部署团体、住民投票团体、地方议会 / 行政目标机构。

5. 法律 / 国际倡议资料：Earthjustice、JELF、Center for Biological Diversity、Save the Dugong Campaign Center、Peace Philosophy Centre 等。

6. 行政 / NPO 资料：可补充法人型 NPO、协作型 NPO、行政部门、制度渠道，但要避免加入大量与核心议题无关的公共服务型 NPO。

这些来源合计的“原始出现名称”超过 150 并不难；真正难的是去重、筛选、确认是否与研究问题相关。

## 3. 为什么不能硬承诺 150-200

主要有五个原因：

1. 重复率高：2010、2015、2020 的边野古 / 环保 / 国际倡议名单会有大量重叠组织。
2. 外部组织多：很多是日本国内或海外支援组织，不是冲绳本地 NGO。
3. 一次性署名多：共同声明中的签名组织不一定是稳定联盟成员。
4. 相关性不一：有些组织只在单一事件中出现，与冲绳长期组织生态关系弱。
5. 确认成本高：若每个 actor 都要有 source_id、issue_tags、place_tags、confidence、evidence_note，人工复核量会明显上升。

## 4. 建议修改交付口径

原口径：

> 150-200 个组织 / 团体 / 网络 / 机构条目。

建议改成：

> 120-180 个公开资料可核查 actor 条目；其中包括冲绳本地民间组织、市民团体、实委会、律师 / 原告团、相关日本国内 NGO、国际倡议组织、法律团体和必要的制度 / 目标机构。若资料质量和去重情况允许，可扩展至 150-200 个。

如果甲方需要更稳：

> 标准一期保证 120 个以上高质量条目，目标 150 个，冲刺 180-200 个。

## 5. 建议分级

| 层级 | 数量 | 可信度 | 含义 |
|---|---:|---|---|
| 保守保证 | 80-120 | 高 | 只收核心组织和高置信来源 |
| 标准一期 | 120-180 | 中高 | 包含冲绳本地 + 日本国内支援 + 国际倡议 + 法律组织 + 部分制度机构 |
| 冲刺上限 | 180-220 | 中 | 需要纳入更多共同声明签署者、行政协作组织、媒体出现组织 |
| 不建议承诺 | 300+ | 低 | 除非做扩展版并接受更多低频/低置信 actor |

## 6. 对报价和工期的影响

如果把标准一期改成“120-180 个 actor”，7 周 / 148,000 RMB 是比较稳的。

如果坚持“150-200 个 actor 且每条都高质量复核”，建议：

- 工期：7-8 周。
- 报价：158,000-178,000 RMB。

如果只要求“出现过即可入库”，150-200 不难，但数据质量会下降，不建议这么做。

## 7. 我的最终建议

对外不要说“确定能做 150-200 个”。应说：

> 公开线上资料可以支撑百余个高质量 actor 条目。标准一期建议承诺 120-180 个可核查 actor，150-200 作为目标上限。若甲方要求每个条目都做较完整的分类、来源、证据和置信度标注，则需要相应增加工期或降低数量目标。
