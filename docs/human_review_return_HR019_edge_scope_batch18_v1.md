- X014 保留为外部资助制度 watchlist；

- 向境外非政府组织提供民主项目 grant；
- 支持人权、法治、独立媒体、公民教育、政治程序和公民社会；
- 部分 active grantee 可因安全原因不公开。

所以“公开名单未命中”不能证明历史上绝无任何间接或未公开联系；但也绝不能反过来猜测存在冲绳关系。

此外，I013 当前定义是：

> U.S. consulate, exchange, scholarship, youth leadership, alliance-related outreach

NED 的一般民主援助／grantmaking 不等于该定义下的公共外交。即使从更宽的政治传播理论看两者可能相邻，也不能在本项目受控 taxonomy 中无证扩写。
