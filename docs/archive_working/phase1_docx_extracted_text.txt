复归后冲绳民间组织 / NGO 分类与议题网络一期研究方案
1. 项目定位
本项目关注 1972 年冲绳复归以来，冲绳民间组织、社会运动组织与 NGO/NPO 网络如何形成、重组和扩展。本期的核心目标是建设一个可复核、可扩展、可上线展示的冲绳民间组织分类底库与重点议题网络原型。后期再考虑扩展完整的 1972 年以来全量历史网络
研究重点是“哪些民间组织参与了这种转化”。前期知事选研究已经发现，反基地 / 反边野古票在 2014 年以后呈现明显的市町村空间结构，尤其是本岛无基地市町村、基地所在地、宜野湾、名护、嘉手纳周边和离岛之间存在差异；但选举模型尚未解释 NGO、市民团体、环保组织、劳工团体、法律支援团体和国际倡议网络在其中扮演的角色
本期项目的核心是先回答三个基础问题：
第一，冲绳有哪些与基地、环保、人权、地方自治、和平运动、生活安全、先岛安全化和国际倡议相关的民间组织？
第二，这些组织如何分类？哪些是反基地组织，哪些是环保组织，哪些是法律 / 人权 / 国际倡议组织，哪些是跨议题桥梁组织？
第三，在边野古、普天间、嘉手纳、与那国、石垣、宫古等关键地点，环保、生活安全、地方自治和军事设施争议是如何在组织层面发生连接的？
尤其考虑加入与那国 / 先岛观察维度。与那国岛是日本最西端，距冲绳本岛约 509km，距台湾约 111km，与那国驻屯地设有与那国沿岸监视队等机构。 这使与那国和先岛地区成为观察“基地 / 自卫队部署 / 环保 / 生活安全 / 地方自治 / 台湾周边安全环境”如何交叉的重要地点
本期成果服务四类目标：
第一，形成一个冲绳民间组织 / NGO 初步分类底库，为长期项目奠定数据基础
第二，为后续多篇论文提供素材和基础，不只服务一篇报告
第三，为后续田野调查、访谈、档案调阅和重点组织追踪提供优先清单
第四，形成可展示、可下载、可持续更新的项目成果，包括研究报告、PPT、数据包、网络图、地点图和在线展示网页

3. 研究对象与边界
本项目研究对象为 1972 年冲绳复归以来，与冲绳基地问题、环境保护、人权、地方自治、和平运动、劳工与社会议题、生活安全、国际倡议以及先岛安全化相关的民间组织网络
为避免把早期尚未法人化的组织排除在外，本项目不以狭义的“NPO 法人”作为唯一研究对象，而采用更宽口径的表述：冲绳民间组织、市民团体、社会运动组织、NGO/NPO、网络型组织、実行委員会、連絡会、協議会等。1998 年以后，再将 NPO 法人作为其中一种正式法律身份单独标注。已经明确，1998 年 NPO 法实施前后是组织法律身份和公开资料可得性的重要分界
3.1 纳入对象
具体来说，纳入范围大概应包括：
市民团体
反基地组织
环保组织
人权组织
和平、劳工、女性、教育、社区、地方自治相关组织
NPO 法人
一般社团、公益法人、任意团体
围绕特定事件形成的実行委員会、連絡会、ネットワーク、協議会
法律支援团体、律师团、原告团、支援会
与冲绳议题发生连接的国际 NGO、海外团体和研究 / 媒体机构
只要某一组织在可查资料中参与了冲绳相关公共议题，即可作为候选主体纳入 actor registry；具有 NPO 法人格且与研究议题相关的组织，应优先纳入并单独标注其法律身份
3.2 本期重点范围
本期采用“整体框架 + 近年重点 + 关键地点”的策略，不追求全历史全量覆盖
时间上：
1972–1997：作为历史背景和组织源流线索，不做全量系统化采集
1998–2012：优先采集 NPO 法人化后较易公开追踪的组织资料
2013–2019：重点关注边野古、县民投票、环保倡议、诉讼和全县性政治化
2020–现在：重点关注国际倡议、环境正义、先岛 / 与那国安全化、生活安全和跨国连接
