# 一期研究深化与选题波次 v1

日期：2026-07-20
状态：负责人已授权启动；全部结果先进入独立研究层
上位问题：冲绳民间组织如何把基地问题转译为环保、生活安全、地方自治、人权、法律程序和国际倡议等议题，并在关键地点扮演何种公开角色？

## 1. 本轮不是重复证明“议题转译”

“组织把地方损害转成制度可受理主张”是一期的既定主问题，不再作为新发现。本轮要解释的是三个更难的问题：

1. 我们看到的网络结构，有多少来自现实协调，有多少来自资料生产、托管和保存能力？
2. 同一基地空间为什么同时存在损害限制／问责组织和驻军生活服务／慈善组织，而公开组织接口似乎很少？
3. 在各地议题分散的情况下，冲绳战记忆与“防止再次成为战场”是否正把先岛部署、台湾有事、撤离和生活安全压缩成新的共同语言？

## 2. 三条优先主线

### H1 少数高承载名单对 actor–issue 可见层的来源依赖

当前证据：

- 295 条来源中，2020 年后占 170 条，1972–1997 仅 4 条。
- 在当前 E3/E4 actor–issue 层中，删除 A001／A004／A005 三个 actor 节点，有边 actor 约从 101 降到 98；若耗尽 S003／S004／S006 三份名单材料独占支持，则降到约 71。两种删除的分析单位和最大影响范围不同，不能当作匹配反事实。
- 单删 S004，连接 actor 约从 101 降到 76，边约从 234 降到 193。
- 三源删除损失的边和有边 actor 约有 84% 由 S004 单独造成；目前首先是单一高承载名单的来源集中问题，不是三类资料宿主重复呈现同一机制。
- 234 条 E3/E4 边中有 12 条没有可解析的 `S` 来源；它们按保守规则不会被 source-ID 删除实验移除。
- 有效 source ref 数与 actor–issue 度只有弱正相关，初算 Spearman 约 0.28。

暂定解释：

> 当前 E3/E4 actor–issue 可见层明显依赖 S004 等少数高承载名单；资料入口的可得性会改变研究者看到的组织—议题覆盖。

这仍是来源敏感性结论。producer／host、官网能力、英文能力、律师或专职人员尚未测量，不能据此说“文档能力制造了中心性”。

竞争解释：

- 专业组织可能既真实协调行动，也更善于留存材料。
- 法律和国际程序本身会强制生产文件。
- 当前样本从大型联署名单起步，偏差可能来自研究设计。
- 法人规模、组织资源同时影响真实持续性和网页能力。

不能写：

- 中心性主要是资料幻象。
- 资料弱的组织寿命更短。
- actor–issue 度等于影响力、协调力或稳定关系中心性。

本轮判定标准：

- 建立 actor–issue edge×source 下钻与全来源 leave-one-out；
- 将 actor 节点删除与 source-support 删除明确作为不同单位的描述性比较；
- 对 source family、事件名单和已核层做敏感性；
- 明确哪些 producer／host／language／capacity 字段仍未知；
- 在生命周期材料不足时停止寿命推断。

定位：所有网络论证的强制方法校正层；当前不作为独立经验发现。

### H2 基地周围并存的两套功能生态

当前证据：

- 当前 registry 规则得到 9 个服务／慈善比较 actor；它们不是基地 private organization／服务组织的总体清单。其有效议题只落在 `military_family_service` 与 `base_community_welfare`。
- 候选锚点规则得到 65 个限制／问责侧候选 actor，其中 18 个至少有一条人审锚点边，47 个只由候选锚点边选入。
- 当前类型化组织关系中，已核 14 条、候选 8 条；尚未观察到服务／慈善侧与损害限制／问责侧之间的直接 dyadic relation。
- 4 条 typed-event 与 35 条 R10 目的性记录也尚未编码直接跨组组织关系；27 条法律案件角色中没有服务侧 actor。这些是不同的小型目的性输入，不是四次独立普查。
- 两侧至少共享嘉手纳等空间节点，因此不是地理上完全分离。

暂定解释：

> 基地的长期存在同时形成损害外部性和驻军生活再生产需求；前者关联限制／问责组织，后者关联照护／服务组织。真正的问题不是两类组织是否都存在，而是它们在共享空间中为何很少形成公开接口。

竞争解释：

- 日文运动资料和英文基地资料构成两个检索宇宙，零交叉可能只是 source silo。
- 人物网络尚未结构化，不能断言没有共享人员。
- AWWA 等完整 recipient 年表缺失，间接接口可能藏在福利设施、学校、社区组织或行政对象中。
- 服务组织不能因基地内生性被自动赋予亲基地立场。

不能写：

- 两套社会完全隔绝。
- 没有共享人员。
- 服务组织亲基地或没有政治态度。
- 基地“生产”两套 NGO 已被因果证明。

本轮判定标准：

- 固定服务侧 actor 集合与透明的限制侧选择规则；
- 比较议题、地点、关系、案件角色、source family；
- 建立 `person–actor–time` 与 recipient crosswalk 的缺口队列；
- 将共同地点、共同活动、共享人物、直接关系、受赠接口分开编码；
- 若跨侧仍为零，只报告限定集合、限定年份和限定公开记录中的“观测为 0”。

定位：高原创性候选论文；下一轮先扩服务侧当前清单、人物与 recipient 接口，再判断限定零值是否有研究意义。

### H3 战争记忆是否正在成为反前线化的共同语言

当前证据：

- 2017 年跨岛部署行动已把避难和居民生活放进跨岛交涉框架。
- 2021–2023 出现 A018、A017、A100、A108 等以“台湾有事／不让冲绳再次成为战场”为核心的新组织或活动。
- 已有 A018 与 A100 成立事件、A108 形成过程之间的接触／组织载体线索；箭头方向和目标组织独立采用尚未确认。
- A101 的 2023 活动得到环境、女性、儒艮、边野古、PFAS、反部署和反战等 13 个团体赞同，是跨议题汇合的直接事件线索。

暂定解释：

> 冲绳战记忆可能通过少数组织者、讲演、成立过程和活动赞同，形成一组可检验的事件级载体路径；是否发生跨组织独立采用或持续共同动员，仍未确认。

竞争解释：

- 2020 年后材料远多于早期，表面增长可能是资料偏差。
- `anti_war` 是后加标签，数据库标签增长不等于现实语言增长。
- 近期只是新增了一批同类组织，未必是旧组织采用了新语言。
- 少数旧运动人员可能只是在新组织中重包装既有语言。
- 同场赞同仍不等于稳定联盟。
- 直接先行研究已经讨论 A017、A108、石垣“不让岛成为战场”与当前军扩—冲绳战类比；新意不能是首次发现二者相连。

不能写：

- 反前线化已经成为整个冲绳民间社会的统一语言。
- 标签数量证明词汇显著增长。
- 一次跨议题事件证明稳定共同运动形成。
- 整个日本对战争记忆的敏感性已由本项目证明。

本轮判定标准：

- H3a：同文体、可比文本中的词汇变化；
- H3b：新语言是否扩散到既有环保、女性、人权、污染与自治组织；
- H3c：是否至少两个事件包含三个以上既有议题家族，并出现重复参与；
- 建立未采用该语言的负案例；
- 把人物／组织载体、事件汇合和稳定关系严格分开。
- 负责人先通读四项直接先行研究，再决定结构化比较是否仍有新增解释。

定位：实证 pilot；是否升为主论文取决于先行研究审读、独立采用证据与负案例。2016–2023 只是拟检验时段，不是已有连续证据时段。

## 3. 其他方向如何嵌入

其他候选不取消，但不再平行铺成完整模块：

- 先岛三地地方化：作为 H3 的比较条件与负案例。
- 公投如何处理民意：作为 H3／既有转译研究的制度结果变量。
- 少数重复骨架＋事件外围：用于检验 H3 是否出现重复共同动员。
- 行政日常 NGO 与基地倡议世界分离：作为 H2 的第三生态／对照层。
- 组织改名、前身、临时实委会与寿命：作为 H1 的生命周期与可见性校正。
- 国际倡议、法律程序、制度让步上限：保留为一期报告主轴和 outcome 基线，不再冒充新选题。

选题登记表见 `outputs/research_wave_topic_selection_v1/topic_register_v1.csv`。

## 4. 数据与前端边界

本轮只创建独立 package，不修改中央 registry、actor–issue、actor–place、AEV、case-role、source log 或现有前端构建契约。

每个 package 必须：

- 有生成脚本、结构化输出、README／brief、验证和人工判断队列；
- 使用 `claim_status=candidate|lead` 或明确的分析状态；
- 使用 `frontend_eligibility=not_frontend_ready`；
- 给出 `source_ids`、`interpretation_limit` 与竞争解释；
- 不把共同出现派生为稳定组织边；
- 不把“数据里没有记录”改写为“现实中不存在”。

以后若接入前端，只能作为新的“研究模块”入口：

```text
当前事实层 → 不变
研究包 manifest → 明确开关后加载
候选观察／敏感性／缺口 → 研究视图
负责人复核并决定 → 才可能升级中央层或已核视图
```

当前统一 JSON 只是模块目录与资产索引，不是行级观察契约；公共边界见 `outputs/research_wave_topic_selection_v1/module_contract_v1.json`。任何前端接入仍须另建、验证并批准行级 export。

## 5. 本轮预期输出

1. H1：当前口径的来源删除／actor 删除敏感性、actor×source 表和字段缺口。
2. H2：两侧 actor、议题、地点、关系与来源对照，以及人物／recipient 接口检索队列。
3. H3：可定位的候选语句、事件—组织—框架观察、扩散载体与可比语料方案。
4. 一张选题雷达：新意、当前证据、关键反证、补料成本和 go／hold 条件。
5. 一组独立人工任务：只要求负责人判断会改变论点强度的条目。

## 6. 负责人下一检查点

第一轮 package 完成后暂停一次，由负责人决定：

1. H3 是否升为主论文，还是仅作一期报告的新章节；
2. H2 是否值得投入人物／recipient 的定向检索和当地材料；
3. H1 是否只作方法附录，还是形成独立的方法论文短稿；
4. 哪些候选解释太强、哪些反例必须补；
5. 是否把 2016–2023 作为论文实际时段，而把“复归后”保留给甲方总报告。

在这一检查点之前，AI可以做机械计算、已指定语料整理、公开文献地图和反例搜索；不替负责人决定最终标题、因果措辞或主论文方向。
