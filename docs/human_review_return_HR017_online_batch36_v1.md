### 1.4 最高裁处分仍应采用中性表达

两类现有来源存在信息层级差异：

- QAB 记载 2024-09-26 最高裁决定“不受理上告”，原告败诉确定；
- CALL4 组织侧案件页记载最高裁同时作出“本件上告棄却”和“本件不作为上告审受理”的决定。

后一种“双重处分”在上告与上告受理申请并行时并不矛盾，但当前仍缺：

- 最高裁官方决定书；
- 最高裁案号；
- 两项程序分别对应的正式案号和原文。

因此正式表可以确认“最高裁程序结束、败诉确定”，但在取得一手决定前，不单独冻结为只有“上告棄却”或只有“不受理”。

来源：

- https://www.qab.co.jp/news/20241007226830.html
- https://www.call4.jp/search.php?items_id=I0000141&items_id_PAL%5B%5D=match+comp&run=true&type=action

### 1.5 A068 名称问题已有充分方向

冲绳县官方沿革在 1997 年条目中明确记载：

- `名護市民投票推進協議会（宮城康博代表）`；
- 1997-06-27 向名护市提出条例制定请求；
- 1997-07-08 获代表者证明并开始法定签名活动。

此前 HR-019 调查还发现：

- 未找到中央 registry 当前名称 `名護市民投票の会` 的史料依据；
- 可靠全称是 `ヘリポート基地建設の是非を問う名護市民投票推進協議会`；
- 其后发生发展性解散／改组，并进入 A019 的组织谱系；
- 这不等于 A068 从 1997 年持续活动至今。

来源：

- https://www.pref.okinawa.jp/kititaisaku/DP-08-13.pdf
- https://www.city.nago.okinawa.jp/kurashi/2018071900226/
- https://www.city.nago.okinawa.jp/kurashi/2018071901216/

所以这不是两个并存组织的拆分问题，也不宜把无来源的旧名仅作为等价 alias 保留；应先修复 A068 的 canonical name，再记录事件角色和后继关系。
