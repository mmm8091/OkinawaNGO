## 1. 纠偏后的总判断

当前成果是一个已经出现若干强解释线索的研究原型，但**尚未达到一期方案验收条件**。

必须恢复以下合同口径：

- actor registry 的一期范围是 120–180 个公开资料可核查 actor。HR-015 撤出九个 E2 一次署名名称后曾降至 118；HR-027 随后按模块价值补入四个 actor。中央 registry 现保留 122 条历史记录，其中 A072 是并入 A071 的重复组织 tombstone，当前有效 actor 为 121，达到合同下限。事件级名称和 tombstone 都不能为凑数回填有效层。
- R1–R11 按方案原文“会全做，按优先级做到不同深度”。不能只完成若干优先模块后，用内部任务表替代方案验收。
- R12 媒体可见度、R13 人物—组织互锁、R14 组织谱系属于扩展模块，不阻塞标准一期；当前 coverage audit 是基础建设成果，不是方案 R14。
- 一期不以“文件存在”验收。每个模块必须同时有数据证据、解释性回答、可读成果和明确边界。

本轮已完成核心 CSV 语法修复、registry issue-tag 规范化及在线人审回填。HR-010 批6（47）→ LCR001–004（4）→ HR-034（50）→ 重生并执行 HR-029（41）→ HR-031（3）的依赖顺序已经闭合；HR-035 Batch 1 的15条与 Batch 2 的23条决定也已合并。当前线上空白人工决定为0；另有12条当地／新一手材料项，当前正式未闭合共12项。

## 2. 模块的统一验收单位

每个基础问题和 R1–R11 模块都必须形成同一套五件套：

1. **问题**：方案要求回答什么，不能偷换成容易完成的问题。
2. **证据产品**：结构化表、来源、evidence note 和人工复核记录。
3. **解释**：当前样本显示了什么机制、差异或类型，而不只是数量。
4. **可视化或等价强成果**：图、案例路径、对照矩阵或机制说明页；形式服从问题。
5. **边界**：能回答什么、不能回答什么，以及缺口是否需要线上补料或当地协作。

只交 CSV、只交图或只交摘要都不算模块完成。

边级补证、HR-034 状态迁移、多语 alias 与 HR-029 最终冻结均已完成；完整网络、议题共现、
桥梁机制和来源删除稳健性图仍须按冻结后中央层统一重绘／核账。

### Q3 关键地点中的议题如何在组织层面连接？

当前最有解释力的阶段性结论是地点分工：

- 边野古/大浦湾：生态与儒艮保护把地方建设争议接到环境程序、法律和国际倡议。
- 嘉手纳/普天间：基地负担、噪音和生活安全更突出，法律原告团是重要组织形式。
- 石垣/宫古：部署争议与住民投票、地下水、生活安全和地方自治交叉。
- 与那国：应按前线/安全环境、地方自治、公投、台湾邻近和生命安全解释，不能强行环保化。

R4 已补出三地安全语料对照图和 entity–frame 图；R3 保留135条历史地点边，其中130条有效（53人审／77候选）、5条 retired。有效先岛 dossier 为与那国6／石垣3／宫古4；AP123 已固定为 P007 Camp Foster。地点×议题替代层按新 actor–issue 层重生为306条有效同源三元事实，其中299条 E3/E4、81条双边人审、97条可附着正式事件观察。

## 10. 当前最重要的解释性主线

现阶段最值得继续验证的不是“冲绳有一个统一 NGO 网络”，而是以下机制：

1. 基地争议通过生态、生活安全、自治、法律和国际倡议被不同组织重新表述。
2. 这种转译具有地点差异：边野古模式不能复制到与那国，嘉手纳/普天间也不同于先岛。
3. 组织关系具有行动类型和制度场域差异；署名、诉讼、公投、行政协作和服务关系不能混成一张联盟图。
4. 外来 actor 的进入进一步说明冲绳民间组织生态包含倡议、法律、行政、服务、慈善和公共外交多层，但这些层不构成同一政治阵营。

后续数据、图和报告都应围绕验证、比较和限制这四条解释推进，而不是以新增文件数量作为完成度。
