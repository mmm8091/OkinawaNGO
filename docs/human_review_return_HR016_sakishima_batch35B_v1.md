## 2. HR016-002 · 宫古 F_AUT 归具名议员个人

### 调查结果

印刷 p.139 的 speaker 顺序明确：

1. 久貝美奈子议员提出先岛有事避难计划问题；
2. 总务部长上地俊暢说明国、县、先岛市町村及其他机关正在研究县外避难；
3. 久貝议员追问市民意见是否有正式反映机制、何时听取市民声音；
4. 总务部长答复将继续推进国民保护措施，并通过宣传等争取居民理解。

其中，直接提出“市民意见是否被反映”“何时听取市民声音”的是久貝议员。记录没有表决、决议或
全体议员共同声明，不能把个人的一般质询写成 `LEG_MIYAKO_COUNCIL / 宮古島市議会` 的机构立场。

总务部长的答复属于宫古岛市行政机关。其答复说明将通过宣传周知，但没有说明已经设置市民参与、
咨询或共同决策机制，因此也不能把它扩写为“市政府已保障居民参与”。

### 辅助建议

**`revise`。**

- R4E008 entity 从 `LEG_MIYAKO_COUNCIL` 改为
  `PROV_COUNCILOR_KUGAI_MINAKO`；
- display name 使用 `宮古島市議会議員 久貝美奈子`；
- event 使用 `先島有事避難計画に関する一般質問`；
- frame 保持 `F_AUT`，但 fact text 限定为“具名议员追问居民意见进入计划的机制与时点”；
- 不称为住民投票主张，也不称为宫古岛市议会立场；
- 总务部长答复作为 `GOV_MIYAKO_CITY_ADMIN` 的独立 institutional response 保存，
  不并入 R4E008。

## 3. HR016-003 · 宫古 F_FTE 应拆成问题方与答复方

### 调查结果

久貝议员在印刷 p.139 的提问中：

- 把政府计划描述为以台湾有事等为设想；
- 提到从宫古、八重山五市町村疏散居民和游客约 12 万人；
- 询问障碍者、住院患者、要照护者、家畜、宠物、财产补偿、移送方式和居民说明；
- 追问市民意见如何进入计划。

印刷 p.140 又由久貝议员提出：

- 全岛民避难后岛上事实上无人；
- 返岛计划和避难后的生活不透明；
- 询问国是否向市长说明。

总务部长的答复则属于另一 speaker：

- 说明县外避难在冲绳县国民保护检讨会等机关间程序中持续具体化；
- 表示将通过宣传周知；
- 承认返岛和避难后生活已作为市民意见出现，并称其为重要课题；
- 表示相关问题今后还要进行意见交换。

两方内容都与 F_FTE 有关，但性质不同：前者是具名议员的问题化／风险质询，后者是行政机关对制度
进度和待解决问题的说明。把两者合成“市议会认为”会丢失 speaker，也会制造不存在的机构共识。

### 辅助建议

**`revise`，拆为两条 observation。**

1. `PROV_COUNCILOR_KUGAI_MINAKO`
   - frame：`F_FTE`；
   - fact：具名议员在一般质询中把台湾有事设想、全岛避难、要照护者、资产、返岛和生活恢复作为
     风险问题提出；
   - evidence nature：individual legislative question。
2. `GOV_MIYAKO_CITY_ADMIN`
   - speaker：`総務部長 上地俊暢`；
   - frame：`F_FTE`；
   - fact：市行政答复说明县外避难正在机关间检讨，并将返岛和避难后生活称为重要但仍待讨论的课题；
   - evidence nature：municipal administrative response。

共同限制：

- 不归给整个宫古岛市议会；
- 不写成已经发生的撤离；
- 不把“计划正在具体化”写成运输、返岛或生活恢复能力已经验证；
- 久貝议员关于政府以台湾有事为设想的说法应标为议员陈述，不能改写成总务部长确认。

来源：

- https://www.city.miyakojima.lg.jp/gyosei/gikai/files/kaigiroku0706.pdf
  （印刷 pp.139–140）

## 4. HR016-004 · 石垣 F_FTE 是匿名会议发言，不是居民 actor

### 调查结果

石垣市官方摘要记载：

- 日期：2024 年 8 月 2 日；
- 地点：伊原间公民馆；
- 主办者：石垣市；
- 参加者：居民 23 人、媒体 2 家；
- 内容：市政府说明避难思路和临时避难设施，并与居民交换意见。

文档随后按 `意見1` 至 `意見9` 编排主题块，但没有说明每一块对应一名不同居民，也没有列出发言者
姓名。23 是参加人数，不是发言人数；九个意见块也不是九个可识别 actor。

可安全进入 F_FTE 的匿名发言内容包括：

- 意见 1：谁可能被要求避难、避难是否具有法律义务、运输工具等问题；
- 意见 2–3：安全前提、航空运输是否可行、在不安全状态下如何避难；
- 意见 4：先岛与冲绳本岛安排差异、全员离岛后谁最后撤离；
- 意见 5：接收能力、要照护者和行政人员配置；
- 意见 6：避难期限、能否返岛和是否被迫放弃岛屿生活；
- 意见 8–9：临时避难设施、要照护者、医疗需求及自然灾害优先性。

这些内容证明“该次会议出现过这些问题”，不能证明 23 名参加者一致，也不能代表石垣市总体。

### 辅助建议

**`revise`。**

- R4E016 不建立 `RESIDENTS_ISHIGAKI` 稳定 actor；
- entity 改为事件层匿名发言集合：
  `EVENT_R4S015_ANONYMOUS_COMMENT_UNITS`；
- entity category 使用 `anonymous_meeting_utterances / non-actor event evidence`；
- frame 保持 `F_FTE`；
- fact text 限定为“2024-08-02 伊原间意见交换会的匿名意见主题块提出若干撤离可行性与生活安全问题”；
- 如正式表允许，优先按 `R4S015_OPINION_01` 至 `09` 保存来源单元，而不是合并成一个网络节点；
- 不进入 actor registry、actor network 或组织计数。

## 7. HR016-011 · R4S015 的匿名意见／行政答复拆分

### 调查结果

该文档的结构是：

- 无箭头的项目符号：匿名意见／问题；
- `→` 后文字：行政答复；
- 多数答复在括号中具名职务，如防灾危机管理课长、总务部长、企画政策长；
- 少数简短答复没有具名具体职务，不能擅自补成某一官员；
- `意見1–9` 是文件的主题分组，不证明一组对应一个人；
- 文件只说参加居民 23 人，没有公布发言者数量、姓名或意见分布。

安全拆分规则：

1. 匿名意见单元保留 `opinion_block` 和项目符号顺序；
2. 箭头后的回答单独保存 `government_response`；
3. 只有括号明确标职务时才填具体行政 speaker；
4. 未标职务的答复只写 `Ishigaki City administrative response, office unspecified`；
5. 不把匿名意见与行政答复拼成单一组织立场；
6. 不把九个主题块写成九名居民，也不把 23 名参加者写成 23 名发言者。

### 辅助建议

**`revise`。**

- R4S015 source locator 改为：
  `pp.1–4／意見1–9；无箭头为匿名意见，箭头后为行政答复；括号职务按原文保留`；
- F_FTE 可由意见 1–6、8–9 的相关匿名短句以及对应行政答复分别支持；
- F_AUT 只由意见 1、4、7 的程序／地方意见短句支持；
- life_safety 可由意见 5、6、9 中要照护者、医疗、返岛生活等明确短句支持；
- source 可进入安全事件／话语层，但不能生成稳定居民 actor；
- 对未回答或标为“回答不需要”的意见 9，不得补造行政答复。

来源：

- https://www.city.ishigaki.okinawa.jp/material/files/group/3/ikenkoukankai_ibaruma.pdf
