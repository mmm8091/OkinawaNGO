# Domain Docs

This is a single-context research repository.

## Before exploring, read these

- `docs/phase1_workbench.md` for current status.
- `data/metadata/coding_schema_v0.md` for field definitions and evidence rules.
- `CONTEXT.md` at the repo root if it exists.
- ADRs under `docs/adr/` if they exist and touch the area being changed.

If `CONTEXT.md` or ADRs do not exist yet, proceed silently. They can be created later when project vocabulary or decisions need to be formalized.

## Domain language

Use the project vocabulary consistently:

- `actor` means a civic organization, NGO, project/network, service organization, sponsor, public institution, or other node included in the registry.
- `edge` means a candidate relationship between actors, issues, places, events, venues, or support/funding roles.
- `evidence_level` means the E0-E4 confidence scheme in `data/metadata/coding_schema_v0.md`.
- `local material collection` means collecting offline or hard-to-access materials; it is not the same as evidence review.

## Current core context

The project is in Phase 1. It is building a verifiable, expandable initial data base for Okinawa civic organizations / NGOs and issue networks. It does not claim to be a full post-reversion NGO history.
