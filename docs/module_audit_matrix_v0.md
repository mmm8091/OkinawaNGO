## 一期模块组合建议

最适合标准一期的组合：

1. B0 数据底座
2. R1 组织分类
3. R2 组织—议题网络
4. R3 地点—议题与与那国/先岛专题
5. R4 环保/生活安全/健康风险框架
6. R5 小样本共同行动网络
7. R7 场域与对象转移
8. R11 跨国/国际倡议样本
9. R14 覆盖与偏差审计

建议弱化或放到扩展：

1. R6 完整媒体可见度
2. R8 行政协作全量资源渠道
3. R9 选举因果连接
4. R10 完整法律资料库
5. R12 人物互锁网络
6. R13 完整长期谱系

## 最重要修正

方案中第 5 节的大方向成立，但标准一期应表述为：

> “冲绳民间组织分类底库与重点议题网络原型”，而不是“复归后全量 NGO 网络演变”。

完整历史网络可以作为长期目标；一期负责证明哪些模块能做、哪些组织值得追踪、哪些地点和议题连接最强。
