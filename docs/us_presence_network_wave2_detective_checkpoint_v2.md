目前最强的制度表述是：**基地内 private organization 保持私人／non-federal 身份，但其在基地内运作的资格由 installation command 授予并可暂停或撤销；MCCS／FSS 承担申请、监测和材料接收等行政职能。**

这套关系应写为 `installation_authorization / administrative_monitoring / compliance_reporting / sanction_authority / facility_license_requirement / reimbursable_support_terms / continuous_resale_exception`，不能写成 funding、affiliation 或 governance control。

## 四、信息公开试验的校正结果

`outputs/us_presence_network_wave2_information_disclosure_pilot_v1/` 已核实：

- 美国 `all_other / non-commercial` 请求人通常有首两小时检索和首 100 页复制免费额度；
- 真实的教育／非商业科学机构请求通常不收检索费，只收第 101 页以后复制费；“做研究”本身不自动取得该身份；
- fee waiver 是独立门槛，须说明披露会显著增进公众对政府活动的理解，且不主要服务商业利益；
- 冲绳防卫局书面请求按一件行政文书 300 日元收费，另有复制／邮寄成本；正式请求仍走表格、柜台或邮寄。

原来三份宽草稿不宜直接发送。未来最小批次改为：

1. WHS：一个 award、既有 SF-425／绩效报告中的地区字段；
2. MCIPAC：一个完整财年的 installation-level balance sheet／P&L；
3. 冲绳防卫局：先咨询文件名和保有部课，再请求 FY2024 的一份既有表。

`no_records`、转送、费用估价、部分不公开或全不公开都可以成为**程序可见性结果**，但只能说明声明机关、期间和文件层的可得性，不能证明底层资金不存在、机关隐瞒资金或某种政治效果。
