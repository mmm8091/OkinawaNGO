# 当地材料收集任务书 v1

日期：2026-07-01

## 0. 这一版改了什么

v0（`docs/local_retrieval_tasks_v0.md`）把 8 个方向一次性列成"未来可能需要当地协作者"的清单，但没有区分"其实线上就能做"和"必须当地人到场 / 进馆内数据库"。

v1 的唯一新增动作：**按成本和确定性分成两层**，把"已经 100% 确定值得做、价值高、难度和成本低"的部分先锁定（Tier 1），随第二轮沟通稿一并交付；真正依赖当地协作者或馆内数据库的留作后续正式派单（Tier 2）。

v0 仍作为每个方向的详细目录保留；v1 是当前的优先级与交付权威入口。

## 1. 分层原则

- **Tier 1 = 现在就做**：材料在公开网络可得（官网、社媒公共页、基地社区报、Internet Archive、内阁府 NPO portal、机构公开年报 / 页面），不需要当地协作者、不需要馆内付费数据库、不需要纸质 / 现场材料。这些是"低成本 + 高价值 + 结果基本可预期"的项，本轮锁定并可交。
- **Tier 2 = 后续派单**：材料只存在于地方报纸馆内数据库、町议会纸质记录、当地保存的意见广告 / 传单实物，或需要现场收集。价值高但成本高、结果不确定，本轮**不承诺时间**，等正式启用当地协作者再派。

分层不改变 v0 里的证据判定要求：年报 / 活动手册 / 官网明确 recipient 记 E4；DVIDS / Stripes 报道 E2–E3；口头转述只作 E1，不进结论。

## 2. 保守口径（不可踩线，沿用全项目规则）

- grant opportunity / NOFO 不写成已拨款或 recipient 关系；只有 award / recipient / contract / 财报 / 项目报告才写入。
- 共同署名 / 共同请求 / 共同在场只写"事件参与"，不写稳定联盟。
- 军属服务 / 慈善组织按观察到的功能编码，不默认亲基地或反基地。
- 与那国按前线 / 安全环境、地方自治、住民投票、台湾邻近、健康 / 生命安全读取，不强行环保化。

## 3. Tier 1 · 本轮锁定 · 线上可完成（可随沟通稿交付）

每项给出：对象、公开可得材料、**本轮交付定义（done_when）**、证据上限。

### T1-A ← LR-003 军属配偶俱乐部慈善 recipient

- 优先级：P1
- 对象：X004 AWWA、X005 NOSCO、X006 KOSC、X007 OESC
- 公开可得材料：各俱乐部官网、Facebook / Instagram 公共页、基地社区报（Okinawa Stripes / DVIDS）公开的 annual charity recipients、thrift shop 收益去向、bazaar / gala program。
- 本轮交付：每个俱乐部一条正式名 + 别名；能在公开页面确认的 recipient 列表（按年份）；每条 donation / grant 边标 E4/E3/E2；标明是否也服务 Okinawan charities（用于功能编码，不下政治结论）。
- 证据上限：官网 / 活动手册明确 = E4；基地社区报道 = E2–E3。

### T1-B ← LR-004 USO Okinawa 赞助与服务网络

- 优先级：P1
- 对象：X001 USO Okinawa、X002 Phoenix Corporation / Phoenix Park Hotel、X003 American Engineering Corporation
- 公开可得材料：USO Okinawa 官网、USO Pacific 新闻、本地 sponsor 公司公开页、基地社区新闻。
- 本轮交付：sponsor 边表（source → USO Okinawa，含年份）；site-presence 表（USO → base / camp）；服务对象说明。金额不能确认的 sponsor 标 E3。

### T1-C ← LR-008 失效网站与 Web Archive 回捞

- 优先级：P3（成本极低，顺手做）
- 对象：A002 Save the Dugong Campaign Center、A008 NGO 非戦ネット、A019 ヘリ基地反対協議会，及其他官网失效组织。
- 公开可得材料：Internet Archive 旧官网 / 声明页 / 活动记录 / 组织简介。
- 本轮交付：每个组织的 archived_url + capture_date + 页面标题 + 可提取字段；判断是否足以把 evidence_level 提升到 E3。同时可回填 MT-003 里相关 inferred_url。

### T1-D ← LR-001（仅线上部分） 冲绳本地 NPO 法人公开报告

- 优先级：P1（仅取线上可得部分）
- 对象：A003 ジュゴンネットワーク沖縄、A012 宮古島いのちの水を守ろう！、A017 沖縄対話プロジェクト、X010 沖縄NGOセンター
- 公开可得材料：内阁府 NPO 法人 portal 的登记 / 事業報告書 / 財務諸表、组织官网可下载资料。
- 本轮交付：每个组织的法律身份（成立 / 改名 / 解散）、役员、活动目的、可在线确认的资金来源。**深层财务 / 委托金额若线上查不到，转 Tier 2，不硬凑。**

### T1-E ← LR-006（仅线上部分） 外务省 / JICA / ONC 已公开报告

- 优先级：P2（仅取线上可得部分）
- 对象：X010 沖縄NGOセンター、X011 JICA沖縄
- 公开可得材料：外务省 NGO 相談員页面、JICA Okinawa 页面、ONC 公开年报 / 活动报告中已发布的协作 / 项目记载。
- 本轮交付：ONC – 外务省 / JICA 边是否可定到 E4 / E3；有金额则记金额、年度、来源页码；可写入报告的 2–3 句事实。**合同 / 委托金额若无公开件，转 Tier 2。**

**Tier 1 汇总交付物**：一份 `local_retrieval_tier1_findings_v1`（可为 CSV + 摘要），每条含 actor_id / edge_id、来源 URL、证据等级、可否写入报告（yes / cautious / no）。这份即可随第二轮沟通稿"顺便交上去"。

## 4. Tier 2 · 需当地协作者 / 馆内数据库（后续正式派单，本轮不承诺时间）

### T2-A ← LR-002 与那国早期反部署组织

- 优先级：P1（价值高、成本高）
- 对象：A014 与那国改革会議、A015 与那国自衛隊配備反対意見広告実行委員会、A016 与那国島の明るい未来を願うイソバの会
- 为什么需要当地：地方新闻原文、町议会记录、住民投票资料、意见广告 / 传单实物主要在县立图书馆 / 馆内数据库或当地保存材料里。
- 交付目标：每个组织是否确认存在、至少一条非党派来源（若能找到）、与那国专题可用的 3–5 条事实句；只能找到党派媒体则仍标 E2。

### T2-B ← LR-007 先岛 / 边野古核心组织报刊数据库

- 优先级：P2
- 对象：A010、A011、A012、A013、A019
- 为什么需要当地：沖縄タイムス（1997 起）/ 琉球新報（1998 起）馆内数据库的首次出现时间、代表人物、主要行动、名称变化。
- 交付目标：每个组织 3–5 条关键时间线，含可引用的日期、标题、报纸名。

### T2-C ← LR-005 美领馆 / 公共外交 recipient（需谨慎）

- 优先级：P2
- 对象：X012 TOMODACHI Initiative、X013 U.S. Consulate General Naha Youth Council Program
- 谨慎点：只有 award / recipient / implementing partner 才写入 registry；仅有 NOFO / grant opportunity 标 `no_public_evidence`，**不得写成已资助事实**。Grants.gov / 领馆页面部分可线上先查，但因政治解释风险高，整条按 Tier 2 谨慎推进，不并入本轮交付。

## 5. 本轮建议执行顺序

1. T1-C 失效网站回捞（最低成本，且能回填 MT-003）。
2. T1-A 军属配偶俱乐部 recipient（MT-005 的线上基础）。
3. T1-B USO 赞助网络。
4. T1-D / T1-E 的线上可得部分（MT-006 的线上基础）。

Tier 2 三项在第二轮沟通稿里只概括为"需当地协作收集的方向"，等人类决定是否派当地协作者后再正式启动。

## 6. 不合格交付示例（沿用 v0）

- 只发链接，没有摘要。
- 只说"查不到"，不说明查了哪些库 / 关键词。
- 没有日期、标题、页码或来源。
- 只给口头判断，没有可复核材料。
- 把社媒转述当成财务证据。
