# 当地材料收集任务书 v1

日期：2026-07-01

状态更新：2026-07-16。W1 线上收口结果见 `outputs/online_completion_v0/`；第三次同步的机制比较新增 T2-D／E／F。

## 0. 这一版改了什么

v0（`docs/local_retrieval_tasks_v0.md`）把 8 个方向一次性列成"未来可能需要当地协作者"的清单，但没有区分"其实线上就能做"和"必须当地人到场 / 进馆内数据库"。

v1 的唯一新增动作：**按成本和确定性分成两层**，把"已经 100% 确定值得做、价值高、难度和成本低"的部分先锁定（Tier 1），随第二轮沟通稿一并交付；真正依赖当地协作者或馆内数据库的留作后续正式派单（Tier 2）。

v0 仍作为每个方向的详细目录保留；v1 是当前的优先级与交付权威入口。

## 1. 分层原则

- **Tier 1 = 现在就做**：材料在公开网络可得（官网、社媒公共页、基地社区报、Internet Archive、内阁府 NPO portal、机构公开年报 / 页面），不需要当地协作者、不需要馆内付费数据库、不需要纸质 / 现场材料。这些是"低成本 + 高价值 + 结果基本可预期"的项，本轮锁定并可交。
- **Tier 2 = 后续派单**：材料只存在于地方报纸馆内数据库、町议会纸质记录、当地保存的意见广告 / 传单实物，或需要现场收集。价值高但成本高、结果不确定，本轮**不承诺时间**，等正式启用当地协作者再派。

分层不改变 v0 里的证据判定要求：年报 / 活动手册 / 官网明确 recipient 记 E4；DVIDS / Stripes 报道 E2–E3；口头转述只作 E1，不进结论。

## 2. 保守口径（不可踩线，沿用全项目规则）

- grant opportunity / NOFO 不写成已拨款或 recipient 关系；只有 award / recipient / contract / 财报 / 项目报告才写入。
- 共同署名 / 共同请求 / 共同在场只写"事件参与"，不写稳定联盟。
- 军属服务 / 慈善组织按观察到的功能编码，不默认亲基地或反基地。
- 与那国按前线 / 安全环境、地方自治、住民投票、台湾邻近、健康 / 生命安全读取，不强行环保化。

## 4. Tier 2 · 需当地协作者 / 馆内数据库（后续正式派单，本轮不承诺时间）

### T2-A ← LR-002 与那国早期反部署组织

- 优先级：P1（价值高、成本高）
- 对象：A014 与那国改革会議、A015 与那国自衛隊配備反対意見広告実行委員会、A016 与那国島の明るい未来を願うイソバの会
- 为什么需要当地：地方新闻原文、町议会记录、住民投票资料、意见广告 / 传单实物主要在县立图书馆 / 馆内数据库或当地保存材料里。
- 交付目标：每个组织是否确认存在、至少一条非党派来源（若能找到）、与那国专题可用的 3–5 条事实句；只能找到党派媒体则仍标 E2。

### T2-B ← LR-007 先岛 / 边野古核心组织报刊数据库

- 优先级：P2
- 对象：A010、A011、A012、A013、A019
- 为什么需要当地：沖縄タイムス（1997 起）/ 琉球新報（1998 起）馆内数据库的首次出现时间、代表人物、主要行动、名称变化。
- 交付目标：每个组织 3–5 条关键时间线，含可引用的日期、标题、报纸名。

### T2-C ← LR-005 美领馆 / 公共外交 recipient（需谨慎）

- 优先级：P2
- 对象：X012 TOMODACHI Initiative、X013 U.S. Consulate General Naha Youth Council Program
- 谨慎点：只有 award / recipient / implementing partner 才写入 registry；仅有 NOFO / grant opportunity 标 `no_public_evidence`，**不得写成已资助事实**。Grants.gov / 领馆页面部分可线上先查，但因政治解释风险高，整条按 Tier 2 谨慎推进，不并入本轮交付。

### T2-D 先岛三地民间组织“问题如何被表述”对照（新增，机制验证主任务）

- 优先级：**P0**；这是当前最值得正式派给当地协作者的任务。
- 研究用途：检验第三次同步提出的比较假设——宫古偏地下水／生活条件，石垣偏自治／公投，与那国偏前线／撤离——究竟来自当地民间组织自己的表述，还是来自线上政府／议会材料更易保存的偏差。
- 对象：
  - 宫古：A012、A013、A112，以及 6・11 集会执行委员会和相关陈情主体；
  - 石垣：A010、A011，以及住民投票请求代表、相关执行委员会；
  - 与那国：A014、A015、A016，以及 2012 意见广告和 2015 公投相关主体。
- 要找的原始材料：组织陈情书、请求书、会报、传单、意见广告、集会资料、声明、组织官网旧页、议会附件、报刊中的完整采访／声明。优先组织自己制作的材料，其次是地方报刊对具名组织的直接引述。
- 每条材料必须记录：`place; actor/provisional_entity; document_date; action_date; title; source_type; newspaper/archive; page/locator; original_japanese_excerpt; local_problem; translated_claim; target_venue; target_actor; action_type; recipient_response; scan_filename`。
- 交付下限：每地 **6–10 条可比较记录**；其中原则上至少 2 条组织自有材料、2 条独立地方报刊／议会附件。确实找不到组织材料时，可以用“检索范围＋无结果记录”替代，不能用行政材料凑数。
- done_when：形成至少 18 条结构统一的三地对照记录，并附每条材料的扫描／照片／PDF 与精确页码；主线程可据此判断第三次同步图 4 的三种地方框架是 `support / revise / reject`。
- 不要求当地协作者判断“哪个框架更强”，只要求完整收集、准确定位和保留原文；解释与编码由主线程完成。

### T2-E 公投制度门槛的一手材料闭合（新增）

- 优先级：**P1**；用于冻结 R9 公投门槛图。
- 与那国：町选管正式结果表、条例第23号及修正文本、町议会审议记录、町长对结果的正式解释；同时收集 2012 意见广告实物。
- 石垣：两次条例案的议案文本与表决记录、两条诉讼链的正式判决／决定书、自治基本条例第27／28条删除的议会材料。
- 名护：1997 投票后市长“接受并辞职”的原始声明、记者会记录或同期地方报纸版面；投票数字已有官方表，不重复抄录即可。
- 交付字段：`case; stage; exact_date; institution; official_title; docket/ordinance_number; result_wording; page/locator; scan_filename; what_it_confirms; what_it_does_not_confirm`。
- done_when：第三次同步图 3 每一个“阻断／重新设计／结果再解释”节点都有可定位的一手或同期高质量地方来源；与那国正式结果表缺失时必须保留灰色缺口，不得用二手数字替代。

### T2-F 1972–2012 组织谱系与关键行动时间线（新增，条件任务）

- 优先级：**P2 / conditional**；只有最终报告或论文继续保留“复归后”长期主张时才启动，不阻断第三次同步。
- 目的：修复当前来源高度集中于 2020 年以后的时间偏差，避免用近期网络反推 1972–2026 长期演变。
- 对象：边野古／大浦湾、嘉手纳／普天间、泡濑和先岛关键组织；优先成立、改名、分裂／扩展、解散、首次公开行动与重大制度入口。
- 时间分层：1972–1989、1990–1997、1998–2012，不能只集中在 2010 年以后。
- 交付目标：30–50 条时间线记录，每条含组织名、当时名称、日期、事件、关系类型、报纸／刊物、版次／页码、扫描件和是否可确认组织连续性。
- done_when：能够明确哪些长期主张有跨期证据，哪些只能收缩为“1998 年以后／线上可见样本”；不得把同名组织自动当成同一实体。

## 6. 不合格交付示例（沿用 v0）

- 只发链接，没有摘要。
- 只说"查不到"，不说明查了哪些库 / 关键词。
- 没有日期、标题、页码或来源。
- 只给口头判断，没有可复核材料。
- 把社媒转述当成财务证据。
