# 组织名录第一张表：前端切片 v1

## 目的

在“总览”或“组织”页首先回答一个简单问题：数据库收录了哪些组织，用户到哪里可以继续核查。名录是进入组织面板、证据抽屉和关系图的入口，不承担网络结论，也不把“有官网”误写成“更重要”。

数据候选来自 `outputs/actor_directory_v1/actor_directory_candidate_v1.csv`。65个非 `not_found` 页面候选已完成字段级人工决定，但候选 CSV 仍是 pre-human 基础层；正式消费须叠加 return、经过受控 overlay 与 publication compiler，前端不直接读取该 CSV。

## 第一张表

桌面端默认列建议为：

1. `组织`：优先显示当前语言的经审定名称；缺失时回落到 `canonical_name_original`。下一行可显示 actor ID 和原名。
2. `类型`：使用 actor class 的三语展示标签，不直接展示内部 snake_case。
3. `来源地`：使用 origin type 的三语展示标签，并明确区分 `us_origin`、`okinawa_local`、`japan_domestic` 等。
4. `正式页面`：显示“官网”“官方分支页”“正式登记页”“母组织页面”徽标与外链。母组织页面必须明确写成母组织页面，不能统称官网。
5. `资料状态`：显示页面是否已有可追溯 source ID、是否有本地归档，以及候选／已核状态。
6. `查看`：打开现有组织详情面板，不新造第二套 actor 页面。

默认按 actor ID 稳定排序；可选择按名称或类型排序。表头附近显示“121 个当前组织”，同时注明 A072 是历史合并记录，不在现行名录中。

## 搜索与筛选

- 统一搜索 actor ID、原名、英文名、日文名和 aliases。
- 按组织类型筛选。
- 按来源地筛选，至少提供“冲绳本地／日本本土／美国来源／国际／公共机构／其他网络”的用户语言分组。
- 按正式页面类型筛选：官网、官方分支页、正式登记页、母组织页面、暂未确认。
- 按资料状态筛选：已核、候选、已归档、尚未归档。

筛选数量按 actor 去重计算，不能把 source crosswalk 行数或归档文件数混作组织数量。

## 空值与指导文案

面向用户的文案应说明下一步能做什么：

- `official_url` 为空：`暂未确认官网或正式组织页面`。
- `name_zh` 为空：直接显示原名；辅助文字为 `暂无经复核中文名`。
- `source_id` 为空但有网址：`新发现的正式页面候选，来源登记待复核`。
- 页面尚未归档：`可访问页面，待纳入本地证据归档`。
- 归档抓取失败：`页面已登记；本地备份待重试`。
- 搜索无结果：`没有符合当前筛选的组织。可清除筛选或改用原文名称搜索。`

避免使用“不是……”“不代表……”组成长段免责声明。必要的证据边界放在页面右上角的“如何阅读”抽屉，用短句解释：`正式页面用于查证组织身份。资金、关系和行动记录请分别查看证据与关系栏目。`

## 下钻

点击组织名进入现有组织面板，至少保留以下顺序：

1. 原名、别名、组织类型与来源地。
2. 正式页面外链及页面类型。
3. 页面依据：source ID、来源标题、证据等级、最近检查日期和本地归档状态。
4. 已核的议题、地点、事件与类型化组织关系。
5. 研究视图才显示的候选事实，继续沿用现有虚线／候选标记。

外链在新标签打开，并使用 `rel="noopener noreferrer"`。证据抽屉显示 source title 和公开 URL；不得把本地绝对路径、缓存路径或哈希暴露到公开包。

## 审定与发布门槛

本候选表不能直接进入“已核视图”。65项审定已执行；其中54个 accept、4个 revise 可进入集成候选，5个 defer、2个 reject 继续排除。每个待发布页面字段至少满足：

- 页面明确属于该 actor，或明确是其上级／正式登记机构托管的页面。
- `url_kind` 与实际归属一致。
- 页面当前可访问；若只能依赖归档，界面应标明“历史页面”。
- 已有 `source_id` 能追溯 source log；新网址应先受控加入 source log 或正式目录 overlay。
- 页面字段的批准不能连带批准组织立场、资金、关系、持续性或其他 registry 字段。

由目录 overlay 叠加正式 return 后进入 publication compiler，并分别生成 reviewed 与 research channel。defer 候选只能在研究视图显示并带状态；reject 不进入默认正式入口。未经受控集成的基础 CSV 不能进入默认已核视图。

## 前端验收

- 名录恰好显示 121 个当前有效 actor；A072 不可搜索、不可计数。
- actor ID 无重复；全量搜索能找到所有 121 个 actor，包括没有官网的 actor。
- 每个正式页面徽标与 `url_kind` 一致，`parent_org_page` 不显示成“官网”。
- 新闻页、活动页、法院材料和第三方介绍页不能进入正式页面列。
- 非空 source ID 均可打开证据抽屉；新网址候选清楚标明尚未进入中央 source log。
- `not_found` actor 仍可进入组织面板，不被隐藏或降级排序。
- 中、日、英模式下都能显示名称回落，不出现空白组织名。
- 页面数量、来源数量和 actor 数量分别计数；任何覆盖率都标明是“正式页面发现率”。
- reviewed 与 research channel 物理隔离，刷新、切换路由和直接访问 URL 后状态不串层。

## 本轮不做

- 不修改中央 actor registry、source log 或 archive manifest。
- 不把页面发现率当作组织影响力或网络中心性。
- 不由官网文字自动抽取资金、人物或组织关系进入正式数据。
- 不在 React 中维护第二份组织名称、类型或 URL 常量表。
