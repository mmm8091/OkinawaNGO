## 0. 批次边界

- 本批只复核来源题名、类型、年份／期间、URL、归档状态、locator、证据级别和支持范围。
- 来源层接受不批准 actor、组织连续性、actor-issue／actor-place edge、关系、金额、联盟、因果解释或政策效果。
- 新闻报道可以支持其明确报道的事件和公开说法，但不替代法院决定书、合同原件或组织历史档案。
- 官方调查汇总的数量和金额只按材料中的统计口径使用，不自动转成 actor 关系、付款或资助。
- 官方合同记录中的“契约金额”不得改写成补助金、实际收款、运动资金或年度总资助。
- 会议记录只支持会议当次的列席、事务局和发言记录，不自动形成长期合作关系。
- 公报中的请求代表者名单是法定程序身份，不是组织成员名册；公开输出原则上不复制私人地址。
- 本报告不修改 HR CSV、中央 source log、archive manifest、actor registry、候选边、图或正文，留待主线程统一合并。
