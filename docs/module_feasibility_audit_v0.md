# 冲绳 NGO / 民间组织分类与议题网络：模块可行性初核 v0

日期：2026-06-08

## 0. 总体判断

新草稿的方向总体可行，而且比原来的“1972 年以来全量网络演变”更适合作为一期项目。最有价值的调整是把目标从“直接做完整历史网络”改成“先做分类底库 + 议题网络原型 + 与那国 / 先岛专题”。这能回应甲方新的关注：NGO / 市民团体到底如何把反基地、环保、生活安全、地方自治和国际倡议连接起来。

但需要修正三个判断：

1. “NGO 分类”不能只靠 NPO 法人名册。很多关键行动主体不是 NPO 法人，而是市民連絡会、住民の会、実行委員会、弁護団、原告団、共同声明网络、地方议员/学者/活动者构成的松散团体。
2. 与那国专题能做，但不要预设为“环保拒止”主轴。与那国公开材料更稳定的框架是自卫队配备、住民投票、电磁波/健康风险、前线化、地方自治、台湾距离和岛内分裂。环保框架在石垣、宫古、边野古更强。
3. “1972 年以来全量组织网络”不适合一期承诺。1997/1998 年以后可用数字报刊、NPO 法人资料、组织官网和声明做系统样本；1972-1990s 前半段更依赖档案、纸本、馆内数据库和访谈，应作为长期扩展。

## 1. 最适合一期的研究问题

建议把一期问题压成：

> 冲绳反基地运动在 2010 年代以来如何通过环保、生活安全、地方自治和国际倡议框架扩展为跨地点、跨议题的民间组织网络？边野古、大浦湾、石垣、宫古、与那国等地点在这个网络中分别扮演什么角色？

这个问题比“冲绳有哪些 NGO”更有研究价值，也比“1972 年以来全量网络”更可操作。

## 2. 数据入口核查

### 2.1 官方法人资料

可行性：高  
价值：中  
风险：容易收集到大量无关 NPO

可用来源：

- 内阁府 NPO 法人ポータルサイト，可检索全国 NPO 法人，含冲绳县法人。
- 冲绳县 NPO プラザ，提供 NPO 法人相关制度、信息公开和咨询入口。
- 冲绳县 NPO 协作实绩调查，如令和6年度《NPO等との協働実績調査》，可看到行政协作项目、协作团体、事业费等。

判断：

官方法人资料适合建立“合法身份层”的组织底库，但不适合直接回答反基地/环保运动网络。关键政治行动主体往往不是 NPO 法人。因此一期必须采用“双入口”：

1. 法人入口：NPO 法人、一般社团、公益法人等。
2. 议题入口：共同声明、住民投票、诉讼、抗议、请愿、新闻报道中出现的任意团体。

### 2.2 共同声明 / 联署资料

可行性：高  
价值：高  
风险：需要处理异名、外部团体和一次性团体

已验证例子：

- 2010 年，WWF Japan 页面显示 67 个国内团体围绕边野古/儒艮/环境保护发表共同声明，并另有 550 多个全球团体署名。
- 2015 年，日本自然保护协会、Peace Boat 等记录了 31 个 NGO 围绕边野古、大浦湾、珊瑚、儒艮的紧急共同声明。
- 2020 年，Okinawa Environmental Justice Project 牵头，71 个冲绳、日本及海外团体向美国 Marine Mammal Commission 提交关于冲绳儒艮和边野古环境影响的请求书和 civil society report。

判断：

这是最适合做组织—议题网络和联盟网络的资料类型。它能稳定抽取：

- 组织名
- 组织类型
- 共同声明关系
- 议题标签：边野古、儒艮、珊瑚、环境影响评价、美国机构、国际倡议
- 跨国关系：日本国内 NGO、冲绳地方团体、美国/海外 NGO、国际机构

### 2.3 地方报刊 / 新闻资料

可行性：中-高  
价值：高  
风险：全量媒体可见度需要数据库权限

公开网页可覆盖一部分关键事件，例如：

- 与那国住民投票、自卫队配备、反对派诉讼意向。
- 石垣岛自卫队配备、市民連絡会、住民投票を求める会、环境/地下水/生态风险。
- 宫古岛自卫队配备、地下水源、ミサイル基地いらない宮古島住民連絡会。

判断：

公开新闻足够做“模块核查”和“重点案例小档案”。如果要做完整媒体可见度，必须依赖冲绳县立图书馆可用的《沖縄タイムス》1997 年后数据库和《琉球新報》1998 年后数据库，或商业新闻数据库。

### 2.4 组织官网 / SNS / Web Archive

可行性：中  
价值：中-高  
风险：组织消失、网页失效、SNS 资料结构差

适合追踪近期组织：

- Okinawa Environmental Justice Project
- Okinawa Dialogue Project
- ノーモア沖縄戦 命どぅ宝の会
- 日本沖縄華僑華人総会等交流类组织
- Rise for Henoko 等国际倡议网站

判断：

组织官网适合做当前组织分类和自我叙述，不适合单独承担历史演变。需要配合新闻、声明和档案。

## 3. 模块逐项核查

### B0. 基础 actor registry

可行性：高  
价值：高  
建议：一期必做

可以实现。初期可先做 150-200 个 actor，但需要明确 actor 不等于法人。建议字段：

- actor_id
- canonical_name_jp
- canonical_name_en
- name_zh
- aliases
- actor_type
- legal_status
- base_location
- primary_place_tags
- issue_tags
- period_active
- source_ids
- confidence
- notes

难点是异名和短期组织。建议先不追求“所有组织”，而是做“议题相关 actor registry”。

### R1. 冲绳民间组织分类与组织生态

可行性：高  
价值：高  
建议：一期核心

这个模块最稳。分类可以先采用多标签制，不要强行把每个组织塞进一个类别。建议一级分类：

1. 反基地 / 反军事设施
2. 环保 / 生态保护
3. 生活安全 / 灾害避难 / 健康风险
4. 地方自治 / 住民投票
5. 法律 / 诉讼 / 原告团 / 弁护团
6. 人权 / 和平 / 反战
7. 劳工 / 教育 / 女性 / 社区
8. 国际倡议 / 跨国 NGO
9. 行政协作 / 公共服务型 NPO
10. 媒体 / 研究 / 支援网络

价值在于：可以直接回答甲方“NGO 起了什么作用”。

### R2. 组织—议题网络

可行性：高  
价值：高  
建议：一期核心

可实现，尤其适合从共同声明和新闻中抽取。初期可做 bipartite network：

- actor -> issue
- actor -> place
- actor -> action_type

可视化能显示哪些组织连接“反基地”和“环保”，哪些连接“地方自治”和“住民投票”，哪些连接“国际倡议”和“美国机构”。

### R3. 地点与空间分布，含与那国 / 先岛专题

可行性：中-高  
价值：高  
建议：一期核心，但范围要收紧

可以做，但与那国不应单独按环保框架强行解释。地点分工建议：

- 边野古 / 大浦湾：环保 + 反基地 + 国际倡议最强。
- 普天间 / 宜野湾：生活安全 + 城市风险 + 基地返还。
- 嘉手纳周边：噪音 + 生活安全 + 基地负担。
- 石垣：自卫队导弹基地 + 住民投票 + 环境/地下水/生态。
- 宫古：导弹/弹药库 + 地下水 + 生活安全。
- 与那国：沿岸监视队 + 住民投票 + 电磁波/健康 + 台湾距离 + 前线化。

与那国专题可做 5-8 页备忘录，但不宜承诺完整组织网络。

### R4. 环保 / 生活安全框架与军事设施争议

可行性：高  
价值：高  
建议：一期核心

甲方提到“当地人似乎想用环保来拒止自卫队和美军”，这个模块最直接回应。核查结果显示：

- 边野古：儒艮、珊瑚、大浦湾生态、环境影响评价、美国 Marine Mammal Commission。
- 石垣：地下水系、生态、噪音、标的化、未实施住民投票。
- 宫古：地下水源、弹药库、导弹配备、生活安全。
- 与那国：健康/电磁波、前线化、弹药/导弹说明不足，环保相对弱一些。

建议表述为“环保/生活安全/健康风险框架”，不要只写“环保”。

### R5. 联盟 / 共同行动网络

可行性：中-高  
价值：高  
建议：一期做小样本，不做全量

共同声明、请求书、公开抗议资料可以抽关系。建议一期只做：

- 2010 67 团体声明
- 2015 31 NGO 声明
- 2019 县民投票相关 NGO 声明
- 2020 71 团体 MMC 请求书
- 先岛 2-3 个住民投票 / 抗议行动样本

这样能做出一张小而有解释力的联盟网络。

### R6. 媒体可见度与“谁在发声”

可行性：低-中  
价值：中  
建议：扩展模块

公开网页可以做示范，但系统媒体可见度需要数据库和检索权限。若没有馆内数据库，容易变成碎片化 Google 结果。建议一期不承诺完整媒体可见度，只做“重点案例新闻可见度样本”。

### R7. 场域与对象转移

可行性：中-高  
价值：高  
建议：一期可做

能做出很好的研究链路：地方抗议 -> 县政/法院 -> 日本中央政府 -> 美国机构 -> 国际 NGO/UN。边野古和儒艮材料尤其强。

典型证据：

- Earthjustice 的 dugong litigation
- OEJP / 71 团体向美国 MMC 提交报告
- 国际 NGO 声明
- Peace Boat / NGO 非战ネット等国际和平网络

### R8. 公开资源 / 行政协作渠道

可行性：中  
价值：中  
建议：扩展模块或背景模块

冲绳县 NPO 协作实绩资料很干净，但它主要覆盖行政协作型 NPO，不一定覆盖反基地/环保抗争主体。这个模块可以用于说明：冲绳民间组织生态不只有抗争，还有公共服务和行政协作；但若甲方重点是基地/先岛/环保拒止，优先级应下调。

### R9. 选举 / 县民投票与市民组织连接

可行性：中  
价值：中-高  
建议：一期只做背景连接

可以和我们前面的知事选研究连接，但不要过早承诺“组织动员影响选票”的因果分析。较稳的做法：

- 2019 县民投票与组织网络
- 2014/2018/2022 知事选中组织公开支持/声明
- 石垣/与那国住民投票运动

### R10. 法律 / 政策 / 环境程序渠道

可行性：中  
价值：高  
建议：一期小样本

可做边野古环境影响评价、儒艮诉讼、石垣住民投票诉讼、与那国工事差止/公开質問状等样本。难点是法院文件和诉讼材料不一定全部公开，可能需要报刊/组织资料替代。

### R11. 跨国 / 国际倡议网络

可行性：中-高  
价值：高  
建议：一期可做样本

这个模块很有价值，因为它解释“反基地如何从地方抗议转化为环境正义、人权、国际倡议”。OEJP、Earthjustice、MMC、Greenpeace、WWF、Peace Boat、Rise for Henoko 都是可用节点。

### R12. 人物—组织互锁与关键经纪人

可行性：低-中  
价值：高  
建议：扩展模块

公开资料可以找到一些关键人物，如 Yoshikawa Hideki、安次富浩、地方共同代表、律师、学者、议员等。但人物网络容易涉及隐私、访谈和不完整资料。建议一期只记录公开角色，不做完整人物网络。

### R13. 组织谱系与长期演变

可行性：低-中  
价值：高  
建议：长期模块

1972 年以来组织谱系很有价值，但需要档案、访谈、旧报纸和组织内部资料。一期可以做“谱系线索表”，不应承诺完整谱系。

### R14. 资料覆盖与偏差审计

可行性：高  
价值：高  
建议：一期必做

必须做。这个项目最容易出现的偏差是：

- 公开资料偏向知名组织和近期组织。
- 法人资料偏向公共服务型 NPO。
- 新闻资料偏向冲突事件。
- 共同声明资料偏向已有网络能力的组织。
- 早期组织和离岛小团体容易被遗漏。

## 4. 模块优先级修正建议

### 一期核心模块

1. Actor registry 与异名表
2. 组织分类与组织生态
3. 组织—议题网络
4. 地点—议题网络，含与那国 / 先岛专题
5. 环保 / 生活安全 / 地方自治框架
6. 小样本联盟 / 共同行动网络
7. 跨国 / 国际倡议网络样本
8. 资料覆盖与偏差审计

### 一期弱化模块

1. 完整媒体可见度
2. 行政协作资源渠道全量整理
3. 选举因果连接
4. 人物—组织互锁
5. 1972 年以来完整谱系

## 5. 报价与工期判断

### 轻量核查版：4 周，60-80 个组织

可行，但更像 feasibility memo。适合先给甲方确认方向。  
建议价格可维持，但交付要明确“不做完整网络”。

### 标准一期：6 周，150-200 个组织

有挑战但可做。前提是：

1. 不做 1972-1990s 全量补全。
2. 不做完整媒体可见度。
3. 不做完整人物网络。
4. 不把所有 NPO 法人都收进来，而是 issue-driven sampling。

建议把标准一期定位为“分类底库 + 重点案例网络原型”，不要叫完整数据库。

### 扩展版：10-12 周，300+ 组织

可作为长期项目一期，但需要明确依赖：

- 报刊数据库
- 档案/图书馆资料
- 可能的访谈
- 更严格的数据清洗和人工复核

## 6. 目前最值得给甲方看的结论

可以这样概括：

> 这个项目可以做，而且价值不小。最稳的切入点不是一开始追求“1972 年以来所有 NGO 全量网络”，而是先做“冲绳民间组织分类底库 + 议题网络原型”。公开资料已经能证明，环保、生活安全、地方自治、住民投票和国际倡议确实是冲绳反基地/反军事设施运动的重要组织框架。边野古和大浦湾最适合做环保—国际倡议链路；石垣和宫古适合做环保/地下水/生活安全与自卫队导弹基地争议；与那国适合做台湾距离、沿岸监视队、住民投票、健康/电磁波和前线化问题。标准一期可以在 6 周内做出 150-200 个组织条目的分类底库和若干网络图，但不宜承诺完整历史网络或完整媒体可见度。

## 7. 下一步建议

1. 先建 `actor_registry_seed_v0.csv`，录入 30-50 个已核查主体。
2. 建 `source_log_v0.csv`，每条资料记录 URL、类型、日期、可抽取字段。
3. 先做三个小样本：
   - 边野古/大浦湾环保与国际倡议
   - 石垣/宫古自卫队配备与环保/生活安全
   - 与那国住民投票与前线化
4. 用小样本结果修正甲方方案里的模块排序、工期和报价。
