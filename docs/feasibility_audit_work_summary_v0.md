## 1. 本轮审计目的

本轮工作不是全面推进 NGO 网络项目，也不是直接开始批量录入组织数据，而是对方案中“第5节 研究模块菜单”逐项做可行性核查，并回头判断“第1节 项目定位”是否能兑现。

用户特别要求：

1. 不能只做 NPO 法人。
2. 不承诺 1972 年以来全量网络。
3. 每个研究模块都要主动探查，不能只给判断。
4. 每个模块都要形成独立核查文档。
5. 完成模块核查后，再判断项目定位里提出的问题是否能搞定。

## 3. 总体结论

项目可以做，而且价值不小。更准确地说：

> 标准一期可以做成“冲绳民间组织分类底库 + 重点议题网络原型 + 与那国 / 先岛专题 + 覆盖偏差审计”，但不应承诺“复归以来全量 NGO 网络演变”。

项目的价值不在于做一个冲绳 NGO 黄页，而在于解释：

- 反基地议题如何被 NGO / 民间组织转译为环保、生活安全、地方自治、国际倡议和前线化风险；
- 哪些组织是跨议题桥梁；
- 哪些地点使用了不同动员框架；
- 冲绳地方议题如何进入日本中央政府、美国机构、国际 NGO、法院和地方自治程序。

## 4. 对第5节模块排序的重新判断

原第5节排序整体方向可用，但需要调整。主要问题有三点：

1. R14 资料覆盖与偏差审计不应排在最后作为选作模块，而应上升为必做质控机制。
2. R11 跨国 / 国际倡议网络和 R10 法律 / 环境程序渠道应上调，因为它们最能解释 NGO 如何把地方基地争议转译到外部制度场域。
3. R6 媒体可见度、R12 人物互锁、R13 长期谱系难度高，不应放入标准一期的硬性交付。

建议调整后的标准一期排序：

1. B0 基础数据底座
2. R14 资料覆盖与偏差审计
3. R1 组织分类与组织生态
4. R2 组织—议题网络
5. R3 地点与空间分布，含与那国 / 先岛专题
6. R4 环保 / 生活安全框架与军事设施争议
7. R5 联盟 / 共同行动网络
8. R11 跨国 / 国际倡议网络
9. R7 场域与对象转移
10. R10 法律 / 政策 / 环境程序渠道
11. R9 选举 / 县民投票与市民组织连接
12. R8 公开资源 / 行政协作渠道
13. R6 媒体可见度与“谁在发声”
14. R12 人物—组织互锁与关键经纪人
15. R13 组织谱系与长期演变

其中 1-10 是标准一期优先模块；11-12 是背景模块；13-15 是扩展模块。

## 5. 对第6节工期与报价的重新判断

原方案三档为：

- A 轻量核查版：4 周，58,000 RMB。
- B 标准一期：6 周，128,000 RMB。
- C 扩展版：10-12 周，220,000-280,000 RMB。

审计后，我建议不要简单降价或涨价，而是调整边界和命名。

### A. 轻量核查版

建议：保留 4 周 / 58,000 RMB。

但名称建议改为：

> 可行性核查与小样本底库版

合理交付：

- 60-80 个 actor。
- source log。
- issue taxonomy 初版。
- 组织分类表。
- 简版组织—议题网络。
- 与那国 / 先岛资料备忘录。
- 1-2 个小样本网络图。
- 模块可行性判断。

不应承诺：

- 完整联盟网络。
- 国际倡议网络完整清洗。
- 完整媒体可见度。
- 人物互锁。
- 长期谱系。

### B. 标准一期

原 6 周 / 128,000 RMB 可以做，但会偏紧。审计后，标准一期若要体现项目真正价值，应纳入 R11、R10 和 R14，因此建议调整为：

> 6-7 周，138,000-158,000 RMB。

如果甲方对价格敏感，也可以保留 128,000 RMB，但必须减少深度：

- R11 只做 1 个边野古 / OEJP / Earthjustice 样本。
- R10 只做法律 / 环境程序样本表，不做深入说明。
- R6、R8、R12、R13 不进入正式交付。

我更推荐的标准一期版本：

- 7 周。
- 148,000 RMB 左右。
- 120-180 个公开资料可核查 actor；150-200 可作为资料允许时的上限目标。
- 3-5 个网络图。
- 3 个专题备忘录：边野古国际倡议、石垣 / 宫古生活安全、与那国前线化。
- coding guide、source log、coverage audit。
- 25-35 页研究报告。

### C. 扩展版

原 10-12 周 / 220,000-280,000 RMB 可以保留为“公开资料扩展版”，但如果甲方希望纳入完整媒体数据库、人物互锁和长期谱系，就应调整为：

> 12-14 周，260,000-320,000 RMB。

原因：

- R6 媒体可见度需要馆内数据库或商业数据库，不是普通网页检索能解决。
- R12 人物互锁有隐私、角色变化和访谈需求。
- R13 组织谱系需要旧报纸、档案和运动史资料。
- 300+ actor 的去重、异名、source_id 和 confidence 标注会显著增加人工复核量。

因此建议把扩展版拆成两种：

1. 公开资料扩展版：10-12 周，220,000-280,000 RMB。
2. 档案 / 媒体 / 人物网络增强版：12-14 周，260,000-320,000 RMB。

## 6. 推荐对外口径

建议对甲方这样说：

> 我们已经对方案中 14 个研究模块做了小样本可行性核查。结论是，项目可以做，但一期应收束为“组织分类底库 + 重点议题网络原型”，不承诺复归以来全量 NGO 网络。模块排序建议调整：资料覆盖与偏差审计应作为必做质控机制，跨国倡议和法律 / 环境程序模块应上调，媒体可见度、人物互锁和长期谱系应放入扩展版。原标准一期 6 周 / 128,000 RMB 可以做压缩版；若要把跨国倡议、法律程序和覆盖审计做扎实，建议调整为 6-7 周、138,000-158,000 RMB，推荐 7 周、148,000 RMB 左右。

## 7. 当前最重要的修改建议

1. 第5节中，R14 不再作为普通选作模块，而作为基础质控机制。
2. 第5节排序中，R11、R10 上调，R6、R12、R13 下调。
3. 第6节中，标准一期工期建议从 6 周改为 6-7 周。
4. 第6节中，标准一期报价建议从 128,000 RMB 改为 138,000-158,000 RMB；对外可报 148,000 RMB。
5. 扩展版应拆分为公开资料扩展版和档案 / 媒体 / 人物网络增强版。
6. 所有版本都必须明确：不承诺 1972 年以来全量网络，不只做 NPO 法人，不把网络图解释为因果图。
