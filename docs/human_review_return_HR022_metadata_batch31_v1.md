## 0. 批次边界

- 本批只复核来源题名、类型、年份／期间、URL、归档状态、locator、证据级别和支持范围。
- 来源层接受不批准 actor、组织连续性、actor-issue／actor-place edge、关系、金额、联盟、因果解释或政策效果。
- 法院判决的法院认定、当事人主张和裁判结论必须分开；匿名判决不得反推具名组织。
- 特别保存事件清单只支持案号、事件名、法院层级和表中明示日期，不能替代判决正文。

- 组织官网支持自述身份和活动功能，不自动支持基地政策立场、地下水议题或行政资金金额。
- 本报告不修改 HR CSV、中央 source log、archive manifest、actor registry、候选边、图或正文，留待主线程统一合并。
