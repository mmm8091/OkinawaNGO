# 对美研究转向：冲绳 NGO 多层社会网络扩展 v1

日期：2026-08-19

状态：第一轮线上普查完成；USN-00／01／02／03 已交付；中央事实层与前端暂不改，等待负责人复核

## 1. 研究问题

下一轮不再只问“这些组织谈什么议题”，而是问：

> 围绕美国在冲绳的军事存在，哪些组织、人物、资金、服务、诉讼和公共外交关系在限制其行动，哪些关系在维持驻军社会及其地方接口；这些作用通过什么机制发生，留下了什么可观察结果？

“阻碍／帮助美国帝国扩张”不直接写成 actor 的二元立场。它拆成可以查证的作用：

- `constraint/accountability`：诉讼、调查、公开记录、赔偿、延误、政策质询、国际问责；
- `garrison_reproduction`：军人军属生活支持、福利、应急、社交和组织连续性；
- `community_mediation`：把基地侧资源送入冲绳福利、教育和儿童机构；
- `public_diplomacy`：青年、交流、资助机会和领馆项目；
- `legitimation_claim`：组织或军方公开把服务解释为伙伴关系、友好或社区贡献；
- `legitimation_effect`：地方接受、信任、态度或政策支持发生变化。这个层级需要独立材料，不能由捐赠事实自动推出；
- `mixed/contested`：同一组织或行动同时产生不同方向的作用；
- `unknown`：现有材料不能判断。

这样既能回应甲方，也能保留反例：VFP-ROCK 是美国来源组织，却参与反军事化；历史上的福利工作也可能继续转译成权利与基地责任主张。

- 当前 registry 有 121 个有效 actor，其中 17 个 `us_origin`。
- 九个是驻军服务／军属慈善比较子集：`X001/X004/X005/X006/X007/X008/X009/X016/X017`。
- 六个是当前对美问责比较子集：`A009/A033/A042/A045/A070/A086`。
- `X013` 是美国公共外交项目节点；`X014` 是 NED 资助观察节点。
- 当前有界 typed-dyadic、事件和 R10 输入中，九个服务 actor 与冻结后 77 个问责比较 actor 之间尚未编码直接组织边；人物网络和完整 recipient 网络未完成，不能写“没有共享人员”。

## 3. 数据库改造目标

每一种关系保留自己的观察单位，不再塞进一张通用关系表。

| 层 | 核心结构 | 主要回答 |
|---|---|---|
| 组织名录 | 组织 → 官网／登记页 → 有效期 → 来源 | 到底收了哪些组织，如何查证 |
| 人物职务 | 人物 → 组织 → 职务 → 起止／观察日期 → 来源 | 谁在组织，谁跨组织连接 |
| 资金资源 | 提供者 → 接收者 → 金额 → 年份 → 用途 → 类型 → 来源 | 谁的钱、以什么形式进入 |
| 服务受赠 | 服务方／中介 → recipient → 物资／服务 → 地点 → 时间 → 来源 | 驻军社会怎样进入地方福利 |
| 诉讼程序 | 组织／人物 → 案件 → 角色 → 目标 → 结果 → 时间 → 来源 | 问责如何进入美国／日本制度 |
| 行动协调 | 组织 → 事件／行动 → 角色 → 对象 → 时间 → 来源 | 谁负责发起、承载、协调、参加 |
| 结构隶属 | 组织 → 上级／分会／伞状网络 → 有效期 → 来源 | 组织由谁构成、归属何处 |
| 合法化材料 | 行动／服务 → 公开正当化话语 → 说话者 → 受众 → 来源 | 谁声称它改善关系或贡献社区 |
| 效果材料 | 行动 → 可观察态度／制度／资源结果 → 方法 → 来源 | 是否真的产生合法化或约束效果 |

前七层可以直接形成多层网络；后两层用于检验解释，不能混成关系边。

## 4. 分层网络方法

不做一张“所有关系毛线球”。正式分析至少保留五张二部或类型化网络：

1. 人物—组织；
2. 资金提供者—recipient；
3. 服务组织—地方受赠机构；
4. 组织—案件／公开行动；
5. 组织—上级／分会／伞状网络。

在各层分别计算连通分量、重复关系、跨层中介和任期重叠。只有观察期相交、身份已经复核、关系类型相容时，才做组织—组织投影。所有中心性结果同时做来源删除和“无官网 actor”敏感性分析，避免把资料留存能力误写成现实影响力。

> 冲绳的民间组织网络一方面提高美国军事存在的问责成本，另一方面承担驻军及其地方接口的日常维持；本研究追踪的不是抽象立场，而是人物、资金、服务、案件和组织结构如何分别产生这两类作用。

## 7. 本轮禁止直接对外写出的句子

- “服务 NGO 为美国基地提供了合法性”——当前最多能证明服务、资源和官方正当化话语；合法化效果仍要测。
- “两套 NGO 没有共享人员”——人物双侧测量尚未完成。
- “美国资助了冲绳某 NGO”——没有 named award／recipient 不得写。
- “六个美国 NGO 长期参与反基地”——A033/A042 当前主要是一次事件证据，应与持续性 actor 分开。
- “中心组织就是最有影响力的组织”——必须同时报告来源依赖和可见性偏差。
