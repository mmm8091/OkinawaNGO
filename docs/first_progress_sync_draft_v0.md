# 复归后冲绳民间组织 / NGO 分类与议题网络——第一次进度同步沟通稿 v0

本周主要完成了项目一期方案的收束和数据底座搭建。根据前期知事选研究的发现，本期研究问题已经调整为：冲绳民间组织 / NGO 如何把基地问题转译为环保、生活安全、地方自治、人权、法律程序和国际倡议等议题；这些组织又如何在边野古、与那国、先岛等关键地点中扮演公开角色。

目前一期不追求“复归以来全量 NGO 网络”，而是先建立一个可复核、可扩展的小型研究底库。研究对象以冲绳本土 NGO、市民团体、住民组织和行动网络为核心，同时补入与冲绳基地社会相关的外来 NGO、军属服务组织、公共外交项目、国际合作组织以及资助 / 委托关系作为观察层。这里不会预设所有组织都属于反基地或亲基地阵营，而是按公开资料中呈现的功能、议题和关系进行分类。

【截图 1：新版方案中“研究对象与边界 / 外来 NGO、军属服务组织与资助关系资料”部分】

数据方面，已经建立初版 actor registry、source log、issue taxonomy、place registry，以及组织-议题、组织-地点和 support/funding sample 三类关系表。当前样本包括 61 条 actor、26 条 source、110 条 actor-issue 候选关系、78 条 actor-place 候选关系和 12 条 support/funding sample edge。现阶段这些关系主要用于搭建研究结构和后续人工复核，并不直接作为最终结论。

【截图 2：actor_registry_initial_v0.csv 表格局部】

从初步样本看，actor 类型已经覆盖冲绳本地市民网络、日本本土环保 / 和平 / 法律 NGO、国际倡议组织、美军基地社区服务组织、军属配偶慈善组织、公共外交项目和资助 / 中介节点。议题层面则覆盖边野古、儒艮 / 生物多样性、反基地、反军事部署、生活安全、地下水、地方自治、住民投票、法律程序、国际倡议、军属服务和公共外交等方向。

方法上，本周已经建立了证据分级和任务分工机制。对资助、委托、赞助和项目合作关系，后续会区分官方记录、财报、项目报告、grant / award / contract、新闻报道和活动页等不同证据等级。只有证据较充分的关系才会进入正式分析；其余只作为待核查线索。同时，项目已建立人工复核任务书、人类决策任务书和当地材料收集任务书，避免把 AI 初筛结果直接当作结论。
