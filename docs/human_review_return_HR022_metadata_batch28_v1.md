## 0. 批次边界

- 本批只复核来源标题、类型、年份／期间、证据级别、locator 和可支持范围。
- 来源层的 `accept`／`accept_with_revision` 不批准 actor、actor-issue／actor-place edge、组织角色、联盟、因果解释或政策效果。
- CALL4 案件页中的原告／组织自述与律师评价，不等同于法院确认；CALL4 托管的判决影印也不等同于法院官网发布。
- 市议会决议、议程和市政府训练资料只支持相应程序文本；不得把“要求”“方案”“训练用”写成已经实施或具有现实输送能力。
- 本轮只做线上调查，不启动当地资料、地方报纸数据库或馆藏任务。
- 本报告不修改 HR CSV、中央 source log、archive manifest、actor registry、候选边、图或正文，留待主线程统一合并。
