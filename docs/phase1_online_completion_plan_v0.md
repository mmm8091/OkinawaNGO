# 一期线上收口、可视化与研究报告推进计划 v0

日期：2026-07-12

## 1. 当前总原则

一期先完成所有公开网络上可合理取得的材料、可解释的核心可视化和研究报告初稿，再正式派当地协作者。当地人力用于解决已经被线上工作明确定位、且确实只能依靠馆内数据库、纸质记录、组织内部年报或现场材料解决的缺口。

这意味着“线上查不到”不是立即派单的充分条件。派单前必须留下检索范围、关键词、访问日期、已查数据库和缺失字段，确保当地协作者拿到的是明确问题，而不是宽泛搜集任务。

## 2. 一期线上收口的完成门槛

以下四项同时满足，才进入当地协作者正式派单阶段：

1. `docs/local_retrieval_tasks_v1.md` 的 Tier 1 全部完成，或逐项形成带检索日志的 `online_exhausted` 结论。
2. 一期核心模块均有“图 + 配套数据 + 解释 brief + 证据边界”，并完成一次跨图一致性检查。
3. 形成一期研究报告 v0，能够说明研究问题、样本与方法、主要模式、案例、局限和下一步当地材料需求。
4. Tier 2 每项均改写为可直接执行的当地任务，包含检索对象、时间范围、馆藏/数据库、所需字段、合格交付格式和优先级。

## 3. Registry 扩展决策

- 不再把“120–150 个 actor”当作机械验收指标；registry 扩展以分析价值、证据质量和模块需要为准。
- 2020 MMC Tier A 的 9 个冲绳本地相关组织已按 E2 signatory-only 纳入，后续做别名和第二来源核实。
- Tier B 的 12 个日本本土/奄美声援组织不直接混入冲绳核心层。只有当线上证据足以支持“日本本土声援层”作为独立分析层、并能改善 R5/R11 可视化或报告解释时，才分层纳入。
- Tier C 的 31 个一次性署名者维持 signatory-only，不进入 registry，除非后续发现持续参与或其他独立证据。
- 新增 actor 必须能回答至少一个明确问题：补足核心地点/议题覆盖、解释事件角色、形成外部声援层、补齐法律/行政/服务功能，或解决已知网络断点。

## 4. 下一轮线上工作流

### W1 线上材料收口

- 完成 T1-A 军属配偶俱乐部公开 recipient 检索；找不到完整年表时，形成逐组织检索日志。
- 完成 T1-D 冲绳本地 NPO 法律身份、公开事業报告和财务资料检索。
- 完成 T1-E ONC / JICA / 外务省公开报告检索；金额不可得时明确记录线上证据上限。
- 复核 S020 是否确属馆内/付费数据库缺口。
- 所有新增真实 URL 进入 source log 后立即归档。

### W2 数据与事件层收口

- 核实 Tier A 9 个 actor 的日文名/别名，按第二来源决定是否补 actor–issue / actor–place 候选边。
- 验证 `actor_relation_events_v1.csv` 后，再决定如何把 event/action/strength 字段合并进主边表；不得把共同署名提升为稳定联盟。
- 补充具有研究价值且线上证据充分的 protest、noise-litigation 或行政协作事件。

### W3 一期可视化收口

现有五个基础模块图保留，但需要审计是否足以覆盖一期研究问题。优先补齐：

1. 组织分类/功能生态图：区分冲绳核心民间组织、外部声援、国际倡议、法律、行政协作、军属服务/慈善等层。
2. 组织—议题网络完整版：在桥接图之外展示主要议题簇、actor 类型和证据边界。
3. 组织—地点矩阵或网络：与地点—议题矩阵互补，说明组织实际公开活动的空间分布。
4. 事件感知共同行动图：区分署名、要请、诉讼、公投及其他行动类型，避免静态“联盟”误读。
5. 证据与覆盖偏差图：展示 E2–E4、线上/当地缺口及不同 actor 层的可见度差异。
6. 资金/委托/服务关系图：只使用 E3/E4，明确区分 grant、commission、sponsorship、service 和 non-funding relation。

每张图必须有生成脚本、配套 CSV、中文图注、可发布范围说明，并能在研究报告中找到对应段落。

### W4 一期研究报告 v0

报告先完成可审阅草稿，不等当地材料全部到齐。建议结构：

1. 研究问题与一期边界。
2. 数据、证据分级与人工复核方法。
3. 冲绳民间组织的功能分类与样本覆盖。
4. 组织如何连接环保、生活安全、地方自治、法律程序与国际倡议。
5. 边野古/大浦湾、宫古/石垣、与那国的地点差异。
6. 共同行动、法律行动与国际化路径；共同出现不等于稳定联盟。
7. 行政协作、军属服务与慈善作为独立观察层。
8. 证据缺口、线上可见度偏差和当地补查需求。
9. 一期结论与二期建议。

## 5. 当地协作者启动方式

达到线上完成门槛后，再从 Tier 2 生成正式派单包。第一批只派高价值且答案可改变报告判断的任务：

- 与那国 A014/A015 的组织级身份和持续性。
- 先岛/边野古核心组织的报刊数据库时间线。
- AWWA/配偶俱乐部 Form 990、Schedule I 或年度 recipient 记录。
- ONC 委托项目金额与年度报告。
- S020 宫古地下水原始报道。

当地材料回收后先进入人工复核日志，再更新数据、图和报告；不直接把协作者的口头判断写入结论。

## 6. 任务交接与验收

- 子任务必须写清输入、允许修改的文件、预期输出和 `done_when`。
- 资料检索、可视化、报告起草可并行，但不得同时修改同一控制文档。
- 主线程负责最终合并、证据口径检查、图文一致性和状态文档回写。
- 每轮只把可复核产出标为完成；`online_exhausted` 与“已获得证据”必须分开记录。
