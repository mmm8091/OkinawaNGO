# 项目定位与核心问题可实现性核查 v0

日期：2026-06-08

核查对象：`复归后冲绳民间组织 _ NGO 分类与议题网络研究方案草稿.docx` 第1节“项目定位”及其提出的核心问题。

## 1. 总体判断

这个项目可以做，而且比单纯做“反基地选举收益”更接近甲方现在关心的主线：冲绳民间组织 / NGO 如何把基地问题转译为环保、生活安全、地方自治、国际倡议和前线化风险问题。

但项目必须明确一期边界。当前最稳的定位不是“复归后 1972 年以来全量 NGO 网络演变”，而是：

> 以公开资料为基础，建立冲绳基地 / 环保 / 生活安全 / 地方自治 / 国际倡议相关民间组织的分类底库，并围绕边野古、大浦湾、普天间、嘉手纳、石垣、宫古、与那国等重点地点，制作若干可验证的组织—议题—地点网络原型。

这个定位既保留长期研究潜力，也避免一期承诺过大。

## 2. 对第1节核心问题的逐项判断

## Q1：冲绳有哪些与基地、环境、人权、地方自治、和平运动、生活安全、先岛安保、国际倡议相关的民间组织 / NGO？

### 可实现性

可做，但必须写成“issue-driven actor registry”，不能写成“全量 NGO 名录”。

公开资料已经能支持一期建立 150-200 个相关主体的底库。这里的主体应包括 NPO 法人、一般社团、任意团体、市民連絡会、住民の会、実行委員会、弁護団、原告団、共同声明网络、国际 NGO 和项目型网络。

### 证据基础

- 官方 NPO 资料可用于法人层组织。
- 共同声明和请求书可用于反基地 / 环保 / 国际倡议网络。
- 地方新闻可用于石垣、宫古、与那国等离岛组织。
- 组织官网可用于近期反前线化、对话项目和边野古现场组织。

### 需要改写的地方

不要让甲方以为我们会从一开始覆盖“冲绳全部 NGO”。应改为：

> 本项目第一阶段建立“议题相关组织底库”，覆盖与基地、环境、生活安全、地方自治、和平运动、先岛安保和国际倡议相关的公开可核查主体。

## Q2：这些组织应如何分类？是否可以区分反基地、环保、法律 / 人权 / 国际倡议、桥接型组织等类型？

### 可实现性

高度可行，是一期最应该做的核心成果。

但分类应采用多标签，而不是单一分类。很多组织同时是反基地、环保、地方自治、国际倡议或法律行动主体。例如边野古相关组织往往同时连接基地反对、儒艮保护、大浦湾生态、环境影响评价和美国机构。

### 推荐分类

1. 反基地 / 反军事设施
2. 环保 / 生态保护
3. 生活安全 / 健康风险 / 噪音 / 水源
4. 地方自治 / 住民投票 / 县民投票
5. 法律 / 诉讼 / 原告团 / 弁护团
6. 人权 / 和平 / 反战
7. 国际倡议 / 跨国 NGO
8. 行政协作 / 公共服务型 NPO
9. 媒体 / 研究 / 支援网络
10. 桥接型组织：同时连接三个以上议题或两个以上场域

### 需要改写的地方

“NGO 分类”不要只按法人状态分类。法人状态只是一个字段，不是研究分类本身。

## Q3：环保、生活安全、地方自治和军事设施争议如何在组织层面连接起来？

### 可实现性

可做，而且这是本项目最有价值的问题之一。

边野古 / 大浦湾最适合展示“基地反对 -> 环保 / 儒艮 / 珊瑚 / 环评 -> 国际倡议”的链路。石垣和宫古适合展示“自卫队部署 -> 水源 / 生态 / 生活安全 / 住民投票”的链路。与那国适合展示“沿岸监视队 -> 住民投票 -> 台湾距离 / 前线化 / 健康风险 / 岛内分裂”的链路。

### 风险

不能把所有地方都强行解释成“环保拒止”。与那国公开材料中，环保框架不如边野古、石垣、宫古强。与那国更强的是前线化、住民投票、台湾距离、健康 / 电磁波、生活安全和地方自治。

### 需要改写的地方

建议写成：

> 本项目不预设所有地方都通过环保框架动员，而是比较不同地点如何分别使用环保、生活安全、地方自治、健康风险和前线化框架。

## Q4：与那国 / 先岛方向是否可以作为重要专题？

### 可实现性

可以做，且战略价值高。但应做成“先岛安保与地方社会反应专题”，而不是单独做成环保专题。

与那国有几个公开资料上很稳定的切入点：

- 与台湾距离近，官方和地方资料都能支撑其战略位置。
- 陆上自卫队沿岸监视队和驻屯地事实明确。
- 2015 年住民投票有公开报道。
- 反对派围绕自卫队配备、健康 / 电磁波、弹药、说明不足和岛内分裂提出问题。

石垣、宫古的环保 / 生活安全框架更强，尤其是地下水、生态、导弹基地、住民投票。

### 需要改写的地方

与那国应被放入“先岛 / 台湾距离 / 前线化”专题；环保拒止可作为石垣、宫古、边野古的强项，与那国只作为可能框架之一。

## Q5：能否研究“NGO 起了什么作用”？

### 可实现性

可以，但应把“作用”拆成可观察机制，而不是泛泛而谈。

建议至少拆成五种作用：

1. 议题转译：把基地问题转成环保、健康、地方自治、国际法、人权或生活安全问题。
2. 组织连接：通过共同声明、请求书、诉讼、住民投票、学习会把分散团体连接起来。
3. 场域转移：把地方抗议带入县政、法院、日本中央政府、美国机构和国际 NGO 场域。
4. 信息生产：制作报告、声明、证言、环境影响批判、请愿材料。
5. 政治动员：推动县民投票、住民投票、选举议题化和地方自治叙事。

这些作用都能用公开资料找到证据。

## 3. 第1节“画的饼”能否兑现？

## 可以兑现的部分

1. 建立冲绳民间组织 / NGO 分类底库。
2. 不只做 NPO 法人，也纳入任意团体、市民連絡会、住民の会、实委会、律师团、原告团。
3. 做组织—议题—地点网络图。
4. 做边野古 / 大浦湾环保与国际倡议链路。
5. 做石垣、宫古、与那国的先岛安保与地方社会反应专题。
6. 解释环保、生活安全、地方自治和国际倡议如何服务于反基地 / 反军事化运动。
7. 形成可复用的数据结构，为长期研究积累底库。

## 需要降级为“一期原型”的部分

1. 1972 年以来完整组织网络演变。
2. 全量媒体可见度。
3. 完整人物—组织互锁网络。
4. 完整跨国网络。
5. 组织对选举结果或公投结果的因果影响。
6. 冲绳全部 NGO 或全部 NPO 法人生态。

这些方向都有价值，但不应作为第一阶段承诺。

## 4. 建议的一期项目定位

建议给甲方的正式表述：

> 本项目第一阶段不追求复归以来所有冲绳民间组织的全量网络，而是先建立一个可核查、可扩展的“冲绳基地与安全议题相关民间组织分类底库”。研究将以边野古 / 大浦湾、普天间、嘉手纳、石垣、宫古、与那国等重点地点为入口，整理公开资料中出现的组织、共同声明、诉讼、住民投票、国际倡议和行政程序，分析冲绳民间组织如何把基地问题转译为环保、生活安全、地方自治、和平反战和国际倡议问题。第一阶段成果将包括组织底库、议题分类、来源日志、若干网络图和重点案例备忘录，为后续长期谱系研究和实地访谈奠定基础。

## 5. 建议的一期核心研究问题

可以把第1节问题压缩成三个：

1. 2010 年代以来，冲绳哪些民间组织 / NGO 在基地、环保、生活安全、地方自治和先岛安保议题中反复出现？
2. 这些组织如何通过共同声明、诉讼、住民投票、国际倡议和行政程序，把地方基地争议转译为更广泛的环保、权利和安全议题？
3. 边野古 / 大浦湾、石垣、宫古、与那国等地点在组织网络和议题框架上有什么差异？

如果甲方坚持长期主线，可以加一个长期问题：

4. 这些组织和议题框架与复归后冲绳反基地运动的长期谱系有什么连接？

但第4个问题应明确为“线索性回答”，不是一期完整回答。

## 6. 最适合一期的交付包

1. `actor_registry.csv`：150-200 个议题相关主体。
2. `actor_alias.csv`：组织异名表。
3. `issue_taxonomy.csv`：议题分类表。
4. `place_registry.csv`：边野古、大浦湾、普天间、嘉手纳、石垣、宫古、与那国等地点表。
5. `source_log.csv`：所有来源记录。
6. `actor_issue_edges.csv`：组织—议题关系。
7. `actor_place_edges.csv`：组织—地点关系。
8. `event_actor_edges.csv`：共同声明、诉讼、请求书、公投等事件—组织关系。
9. 3-5 张网络图或 Sankey / bipartite 图。
10. 3 个专题备忘录：边野古国际倡议、石垣 / 宫古生活安全、与那国前线化。
11. `coverage_audit.md`：说明资料覆盖、偏差和不能推论的事项。

## 7. 项目价值判断

这个项目的价值不在于做一个“冲绳 NGO 黄页”，而在于解释：

- 为什么反基地运动能跨越单一基地议题，扩展为环保、生活安全、地方自治和国际倡议；
- 哪些组织承担了议题转译和网络连接功能；
- 为什么边野古、石垣、宫古、与那国的动员框架并不相同；
- 冲绳民间组织如何在日本中央政府、美国机构、国际 NGO 和本地自治之间移动。

这比只看选举数据更接近“社会运动基础设施”的研究，也更能服务甲方后续可能关心的台海、先岛、与那国和地方社会反应问题。

## 8. 最关键的风险控制

1. 不说全量，只说公开资料下的议题相关底库。
2. 不只做 NPO 法人，明确纳入非正式团体。
3. 不把共同署名等同于稳定联盟。
4. 不把与那国强行环保化。
5. 不把人物公开角色扩展成私人关系网络。
6. 不把网络图解释为因果图。
7. 每一条 actor 和 edge 都必须有 source_id、confidence、review_status。

## 9. 最终判断

第1节的方向可以保留，但措辞要降一点、边界要清一点。这个项目不是不能做，恰恰相反，它能做出很有价值的一期成果；只是必须从“宏大历史网络”改成“可核查的分类底库 + 重点议题网络原型 + 长期谱系线索”。
