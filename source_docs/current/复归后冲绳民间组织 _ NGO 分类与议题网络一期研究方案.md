# 复归后冲绳民间组织 / NGO 分类与议题网络一期研究方案

## 项目定位



本项目关注 1972 年冲绳复归以来，冲绳民间组织、社会运动组织与 NGO/NPO 网络如何形成、重组和扩展



但本期项目的研究重点是，围绕前期[反基地立场的选举收益：冲绳知事选举中的阶段性变化（1990–2022）](https://exl1vtx2gna.feishu.cn/wiki/FuHCw3E2aiyBY1k3Osacf0XBncb?from=from_copylink)的发现和课程展示需求，完成一项**可写、可复核、可继续扩展**的小型研究


本期项目的主问题是：

> **冲绳民间组织 / NGO 如何把基地问题转译为环保、生活安全、地方自治、人权、法律程序和国际倡议等议题？这些组织在边野古、与那国、先岛等关键地点中扮演了什么样的公开角色？**
> 
> 



前期研究已经说明，反基地 / 反边野古立场在选举中具有阶段性和空间差异，但尚未解释 NGO、市民团体、环保组织、法律支援团体、劳工组织和国际倡议网络如何参与议题转化。前期研究回答了“反基地议题在选举中如何表现”，本期研究要回答“这些议题是通过哪些组织、哪些框架、哪些地点和哪些制度场域被组织起来的”。



本期项目回答三个基础问题：



第一，冲绳有哪些与基地、环保、人权、地方自治、和平运动、生活安全、先岛安全化和国际倡议相关的民间组织？

第二，这些组织如何分类？哪些是反基地组织，哪些是环保组织，哪些是法律 / 人权 / 国际倡议组织，哪些是跨议题桥梁组织？

第三，在边野古、普天间、嘉手纳、与那国、石垣、宫古等关键地点，环保、生活安全、地方自治和军事设施争议是如何在组织层面发生连接的？



尤其考虑加入与那国 / 先岛观察维度。与那国岛是日本最西端，距冲绳本岛约 509km，距台湾约 111km，与那国驻屯地设有与那国沿岸监视队等机构。 这使与那国和先岛地区成为观察“基地 / 自卫队部署 / 环保 / 生活安全 / 地方自治 / 台湾周边安全环境”如何交叉的重要地点



本项目以冲绳本土民间组织为核心，同时纳入与冲绳基地、安全议题和地方社会发生实质连接的外来 NGO、国际倡议组织、军属服务组织、公共外交项目和资助 / 委托机构。研究不预设所有组织都属于反基地阵营，而是区分倡议型、服务型、公共外交型、国际合作型和资助型 actor，分析它们如何共同构成冲绳基地社会的民间组织生态。



**本期成果服务四类目标：**

**第一，一份完整研究报告 ，以及一篇可供课程使用、后续继续打磨的论文草稿**

**第二，形成可展示、可下载、可持续更新的项目成果**

**第三（可扩展），形成一个冲绳民间组织 / NGO 初步分类底库，为长期项目，同领域的论文写作奠定数据基础**

**第四（可扩展），为后续田野调查、访谈、档案调阅和重点组织追踪提供优先清单**

## 研究对象与边界



本项目研究对象为 1972 年冲绳复归以来，与冲绳基地问题、环境保护、人权、地方自治、和平运动、劳工与社会议题、生活安全、国际倡议以及先岛安全化相关的民间组织网络

为避免把早期尚未法人化的组织排除在外，本项目不以狭义的“NPO 法人”作为唯一研究对象，而采用更宽口径的表述：**冲绳民间组织、市民团体、社会运动组织、NGO/NPO、网络型组织、実行委員会、連絡会、協議会等**。1998 年以后，再将 NPO 法人作为其中一种正式法律身份单独标注。已经明确，1998 年 NPO 法实施前后是组织法律身份和公开资料可得性的重要分界



### 纳入对象



具体来说，纳入范围大概应包括：

- 市民团体

- 反基地组织

- 环保组织

- 人权组织

- 和平、劳工、女性、教育、社区、地方自治相关组织

- NPO 法人

- 一般社团、公益法人、任意团体

- 围绕特定事件形成的実行委員会、連絡会、ネットワーク、協議会

- 法律支援团体、律师团、原告团、支援会

- 与冲绳议题发生连接的国际 NGO、海外团体和研究 / 媒体机构

- 与美军基地社区相关的外来服务型组织、军属福利组织、军属配偶慈善组织、美国或国际 NGO 在冲绳的分支 / 项目 / 服务网络

- 与冲绳议题相关的公共外交、国际交流、青年培训、奖学金、JICA / 外务省 / 美国使领馆相关项目

- 作为资助方、委托方、项目中介或制度节点出现的政府机构、基金会、企业赞助方和国际组织



只要某一组织在可查资料中参与了冲绳相关公共议题，即可作为候选主体纳入 actor registry；具有 NPO 法人格且与研究议题相关的组织，应优先纳入并单独标注其法律身份，这些 actor 不自动归入“反基地”或“亲基地”阵营，而按实际功能和证据分别标注



### 本期重点范围



本期采用“整体框架 \+ 近年重点 \+ 关键地点”的策略，不追求全历史全量覆盖



时间上：

- **1972–1997**：非重点，作为历史背景和组织源流线索

- **1998–2012**：优先采集 NPO 法人化后较易公开追踪的组织资料

- **2013–2019**：重点关注边野古、县民投票、环保倡议、诉讼和全县性政治化

- **2020–现在**：重点关注国际倡议、环境正义、先岛 / 与那国安全化、生活安全和跨国连接

### 研究数据底座 \+ 研究报告 \+ 甲方论文



复述

本期研究从前期[反基地立场的选举收益：冲绳知事选举中的阶段性变化（1990–2022）](https://exl1vtx2gna.feishu.cn/wiki/FuHCw3E2aiyBY1k3Osacf0XBncb?from=from_copylink)扩展。前期研究已经说明，反基地 / 反边野古立场在选举中具有阶段性和空间差异，但尚未纳入 NGO、市民团体和民间组织动员变量



研究项目和论文相对独立，图表、数据有后续扩展性



研究项目的主问题是：

> **冲绳民间组织 / NGO 如何把基地问题转译为环保、生活安全、地方自治、人权、法律程序和国际倡议等议题？这些组织在边野古、与那国、先岛等关键地点中扮演了什么样的公开角色？**
> 
>
